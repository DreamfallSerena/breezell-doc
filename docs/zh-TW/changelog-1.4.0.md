# Breezell 1.4.0 更新日誌

**發布時間：2026-09-26（美西時間）**

## 新增

### 模型與能力

- 預新增模型：GLM-5.5 Flash、GLM-5.4、Kimi K4、DeepSeek V4.1 Pro、Muse Spark 1.4。
- Image Studio 支援 Hy Image 3.5 與 Qwen Image 2.1。

## 互動與設計

- 方案預覽改用編輯器目前主題與專案 Design Token，不再套用固定色板。
- 未宣告的 CSS 變數會返回說明，而不是直接導致請求失敗。
- 工作區存在 `DESIGN.md` 時，會寫入流程提示。
- 確認後的方案會保存至 `.breezell/design/` 獨立 HTML 文件。
- 工具結果統一指向規格、計畫與實作來源，避免方案與實現偏離。

## 通知

- 通知面板改為左側列表、右側詳情。
- 重要通知固定置頂。
- 列表與詳情區域獨立滾動。

## 修復與優化

- 建立分支前會複製原始會話內容。
- 長對話改為漸進式載入。
- 串流程式碼高亮改為增量更新。
- 刪除會話後立即壓縮資料庫並回收空間。
- SCM 歷史列表快取變更路徑，提升大量檔案場景效能。
- 減少語言、設定與 OAuth 狀態造成的不必要重新渲染。
