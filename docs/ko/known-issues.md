# 알려진 문제

Breezell 버전 1.2.8에서 다음 문제를 확인했습니다. 문제 해결을 위해 작업 중이며, 진행 사항이 있을 때 업데이트를 공유하겠습니다.

## 일부 대화가 로드되지 않는 문제

> **상태: 수정됨**

이 문제는 수정되었습니다. 데이터와 대화 내용은 안전하며 손실되지 않습니다.

## Entanglement 모드 출력 형식 문제

> **상태: 수정됨**

이 문제는 수정되었습니다.

## 원인 불명의 충돌

> **상태: 조사 중**

일부 Breezell 창이 알 수 없는 이유로 예기치 않게 충돌하거나 종료될 수 있습니다. 현재 이 문제를 조사 중이며, 추가 정보가 확인되는 대로 안내하겠습니다.

## 내장 브라우저에서 웹 페이지를 열면 빈 페이지가 표시되는 문제

> **상태: 수정됨**

이 문제는 수정되었습니다.

## Analyze 모드에서 응답 끝에 태그가 노출되는 문제

> **상태: 수정됨**

이 문제는 수정되었습니다.

## Codex 모델의 사용자 지정 컨텍스트 창 설정이 적용되지 않는 문제

> **상태: 수정됨**

gpt-5.6-sol의 컨텍스트 창을 512K(512,000토큰)로 설정한 후에도 새 대화에서 Breezell은 최대 컨텍스트를 272K로 계속 표시했습니다. 클라이언트를 다시 시작하거나 새 대화를 만들어도 설정이 적용되지 않았습니다.

이 문제는 수정되었습니다. 이제 Breezell은 설정된 사용자 지정 컨텍스트 창을 올바르게 적용하고 표시합니다.

## Grok 직접 로그인 기능의 할당량 표시 오류

> **상태: 수정 중**

Grok 직접 로그인 사용 시 사용 가능한 할당량이 올바르게 표시되지 않을 수 있습니다. 이 문제를 수정하고 있습니다.

## 기다려 주셔서 감사합니다

문제를 최대한 빨리 해결하기 위해 노력하고 있습니다. 이해와 기다림에 감사드립니다.
