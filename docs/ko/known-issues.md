# 알려진 문제

다음 문제는 Breezell 버전 1.2.8에서 발견되었습니다. 모두 수정되었으므로, 이 중 하나가 아직 나타난다면 최신 버전으로 업데이트하세요.

| 문제 | 상태 | 세부 정보 |
| --- | --- | --- |
| 일부 대화가 로드되지 않음 | 수정됨 | 데이터는 손실되지 않았습니다. 대화와 그 내용은 안전합니다. |
| Entanglement 출력의 형식이 잘못됨 | 수정됨 | [Entanglement 모드](/entanglement-mode-overview)를 참고하세요. |
| 예기치 않은 충돌 | 수정됨 | |
| 내장 브라우저에 빈 페이지가 표시됨 | 수정됨 | [Breezell Browser](/dialog-box-overview#browser)를 참고하세요. |
| Analyze 모드에서 답변 끝에 태그가 남아 표시될 수 있음 | 수정됨 | [Analyze](/mode-selection#analyze)를 참고하세요. |
| Codex 모델에 사용자 지정 컨텍스트 창이 적용되지 않음 | 수정됨 | `gpt-5.6-sol`을 512K로 설정한 후에도 새 대화에는 최대 272K가 계속 표시되었습니다. 이제 Breezell은 설정한 창을 적용하고 표시합니다. [Context, Reasoning, Fast](/custom-api#context-reasoning-and-fast)를 참고하세요. |
| Grok 로그인에 잘못된 할당량이 표시됨 | 수정됨 | |
| 컨텍스트 창을 전환한 후 자동 압축이 실행되지 않음 | 수정됨 | 이제 대화가 예상대로 다시 압축됩니다. [컨텍스트 사용량과 압축](/dialog-box-overview#context)을 참고하세요. |
| 드롭다운 메뉴가 시스템 기본 스타일과 좁은 테두리로 표시됨 | 수정됨 | |
| Kimi 모델의 추론 강도 설정이 작동하지 않음 | 수정됨 | |
| 메시지를 보낼 때 채팅 화면이 끊길 수 있음 | 수정됨 | |

이 가이드의 설명대로 작동하지 않는 부분이 있으면 [문제 해결](/troubleshooting)을 참고하거나, Breezell 버전과 표시되는 내용을 함께 적어 문의해 주세요.

기다려 주시고 문제를 제보해 주셔서 감사합니다.
