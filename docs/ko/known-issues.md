## Codex 모델의 사용자 지정 컨텍스트 창 설정이 적용되지 않는 문제

> **상태: 수정됨**

gpt-5.6-sol의 컨텍스트 창을 512K(512,000토큰)로 설정한 후에도 새 대화에서 Breezell은 최대 컨텍스트를 272K로 계속 표시했습니다. 클라이언트를 다시 시작하거나 새 대화를 만들어도 설정이 적용되지 않았습니다.

이 문제는 수정되었습니다. 이제 Breezell은 설정된 사용자 지정 컨텍스트 창을 올바르게 적용하고 표시합니다.
