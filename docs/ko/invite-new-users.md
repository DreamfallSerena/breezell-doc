# 새 사용자 초대 방법

Breezell에서는 계정 전용 초대 링크를 생성하여 새 사용자와 공유할 수 있습니다. 조건을 충족하는 초대 사용자가 등록을 완료하고 초대를 수락하면 Entanglement 및 Teams 잠금 해제 진행 상황에 반영됩니다.

## 시작하기 전에

Breezell 계정이 있고 공식 웹사이트에 로그인되어 있는지 확인하세요.

## 공식 웹사이트와 프로필 메뉴 열기

1. Breezell 공식 웹사이트 [https://breezell.com](https://breezell.com)을 엽니다.
2. 로그인하지 않았다면 Breezell 계정으로 로그인합니다.
3. 페이지 오른쪽 상단의 프로필 아바타를 클릭합니다.

![프로필 아바타가 강조 표시된 Breezell 공식 웹사이트](/invitation-guide/open-profile-menu.png)

## Profile 페이지 열기

1. 계정 메뉴에서 **Profile**을 찾습니다.
2. **Profile**을 클릭하여 프로필 페이지를 엽니다.

![Profile이 강조 표시된 계정 메뉴](/invitation-guide/select-profile.png)

## 초대 링크 생성

1. Profile 페이지 왼쪽에서 **Account**를 선택합니다.
2. **Unlock Entanglement and Teams Modes** 섹션을 찾습니다.
3. **Generate invite link**를 클릭합니다.

![Account 페이지의 Generate invite link 버튼](/invitation-guide/generate-invite-link.png)

## 친구에게 초대 보내기

링크를 생성하면 Breezell에 다음과 유사한 메시지가 표시됩니다.

```text
Can you help me unlock this? I'm waiting in the Breezell editor.
https://breezell.com/mode-invite/entanglement?token=YOUR_INVITE_TOKEN
```

위 Token은 자리표시자일 뿐입니다. 본인 계정에서 실제로 생성된 전체 메시지와 링크를 복사하여 친구에게 보내세요.

친구는 링크를 열고 등록하거나 로그인한 뒤 초대를 수락할 수 있습니다. 조건을 충족하는 새 사용자가 필요한 등록 절차를 완료하면 잠금 해제 진행 상황에 반영됩니다.

## 이 방식이 필요한 이유

이번 조정으로 불편하거나 불쾌한 경험을 드릴 수 있어 죄송합니다. Breezell은 인프라, 유지 관리 및 지속적인 개발 비용을 충당하기 위해 꾸준한 재정 지원이 필요합니다.

프로젝트를 지원하고 Breezell이 장기적으로 안정적인 운영을 이어갈 수 있도록 도와주셔서 감사합니다.
