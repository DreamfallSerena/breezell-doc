# Agents 페이지

Agents 페이지는 Breezell의 페이지 중 하나로, **모든 프로젝트의 대화를 한곳에 모아** 보여 줍니다. 왼쪽 사이드바에는 각 프로젝트와 그 대화가 나열되고, 오른쪽은 IDE와 같은 편집기 영역이라 파일, 대화, 내장 브라우저를 나란히 열 수 있습니다. 프로젝트마다 창을 먼저 열지 않아도 각 AI가 무엇을 하는지, 어느 쪽이 답변을 기다리는지 볼 수 있고, 여기서 바로 대화를 이어 갈 수 있습니다.

이 가이드는 Agents 페이지가 처음 나온 Breezell 1.4.58을 설명합니다. 페이지 전환, 사이드바의 각 부분, 프로젝트 추가, 대화 메뉴, 다른 프로젝트의 대화를 다루는 방법, 오른쪽 패널, 계정 막대, 다중 프로젝트 작업 영역, 현재의 제한을 다룹니다.

## 페이지로 이동하기 {#open}

제목 표시줄에 전환 스위치가 있습니다: **Agents | IDE | Box**. **Agents**를 누르면 이 페이지, **IDE**를 누르면 익숙한 편집기, **Box**를 누르면 모델, 기능 옵션, Breezell의 모든 설정 페이지로 이동합니다.

- 새 창은 기본적으로 Agents 페이지로 열립니다.
- 창을 닫았다가 다시 열면, 닫을 때 보고 있던 페이지(Agents, IDE 또는 Box)로 돌아옵니다.
- 파일을 보여 주려고 연 창(예: Breezell로 파일을 열 때)은 항상 IDE로 열립니다.
- 새 창이 Agents 페이지로 열리지 않게 하려면 페이지 오른쪽 위의 **기타 옵션**(⋯)을 눌러 **창을 열 때 이 페이지 표시**의 체크를 해제하세요. **설정**에서 "Agents page"를 검색해 "Open new windows on the Agents page"의 체크를 해제해도 됩니다(이 설정의 문구는 영어입니다).

| 용어 | 의미 |
| --- | --- |
| 프로젝트 | 폴더(또는 다중 폴더 작업 영역). 이 컴퓨터, WSL, SSH 어디에나 있을 수 있습니다. |
| Agent | 대화 하나. 사이드바의 모든 대화가 Agent입니다. |
| 서브에이전트 | 다른 대화가 시작한 대화. 시작한 대화 아래에 나열됩니다. |
| 오른쪽 패널 | 페이지 오른쪽의 편집기 영역. 파일, 대화 탭, 내장 브라우저가 나란히 열립니다. |

## 사이드바 {#sidebar}

사이드바 맨 위에는 네 가지 항목이 있습니다.

- **새 채팅**: 이 창의 프로젝트에서 새 대화를 시작합니다.
- **Box**: Box 페이지로 전환합니다.
- **사용자 지정**: 규칙, 메모리 및 스킬.
- 검색 버튼(**대화 검색**): 검색 상자를 엽니다. 키워드를 입력하면 대화가 걸러집니다. `Esc`를 누르면 지우고 닫습니다.

그 아래가 **에이전트** 섹션으로, 대화를 프로젝트별로 나열합니다.

- 가장 먼저 이 창의 프로젝트가 나옵니다. 그다음에 대화가 있는 다른 프로젝트와 직접 추가한 프로젝트가 최근에 쓴 순서로 이어집니다.
- 프로젝트 줄에는 환경(예: `WSL: ubuntu`, `SSH: host`), 마지막으로 사용한 시점, **+**가 표시됩니다. **+**(툴팁 "{프로젝트 이름}에서 새 Agent")를 누르면 그 프로젝트에서 새 대화를 시작합니다.
- 대화 앞의 점은 상태를 나타냅니다: **작업 중**, **응답 대기 중**, 또는 유휴(표시 없음). 점 옆에는 그 대화의 경과 시간이 "방금", "5분", "2시간"처럼 표시됩니다.
- 프로젝트의 대화가 많으면 **더 보기**를 눌러 펼칩니다.

사이드바를 숨기려면 왼쪽 위 버튼(**사이드바 전환**)을 누르세요. 숨겨져 있는 동안에는 페이지 맨 위에 다시 여는 버튼과 **새 채팅** 버튼이 나타납니다.

## 정렬 방식 {#group-by}

**에이전트** 제목 옆의 필터 버튼(**정렬 방식**)에서 세 가지를 고를 수 있습니다.

- **프로젝트별**: 프로젝트마다 한 그룹. 기본값입니다.
- **시간순**: 모든 대화를 최신순으로 한 목록에 보여 주며, 각 줄에 어느 프로젝트의 대화인지 표시합니다.
- **상태별**: **진행 중**, **답변 대기**, **기타** 세 그룹. 어느 Agent가 나를 기다리는지 한눈에 알 수 있습니다.

## 프로젝트 추가 {#add}

사이드바에는 대화가 있는 프로젝트가 나열됩니다. 폴더를 처음부터 보이게 하려면 **에이전트** 제목 옆의 폴더 버튼(**프로젝트 추가…**)을 누르세요.

- 고를 수 있는 곳이 하나뿐이면 곧바로 폴더 선택 창이 열리고, 여러 폴더를 한꺼번에 고를 수 있습니다.
- 고를 수 있는 곳이 여러 곳이면 먼저 메뉴가 나옵니다. 이 컴퓨터의 창에서는 **Windows 폴더 추가…**, WSL이 있으면 **WSL 폴더 추가…**도 나옵니다. WSL 또는 SSH 창에서는 **{환경 이름}의 폴더 추가…**입니다. 전에 사용한 환경(예: SSH 호스트)은 **{환경 이름}의 프로젝트 추가…**로 나열되며, 그곳의 프로젝트를 체크하거나 전체 경로를 직접 입력할 수 있습니다. 맨 아래는 **다른 호스트에 연결…**입니다.

추가한 프로젝트는 제거할 때까지 사이드바에 남습니다.

프로젝트 줄을 마우스 오른쪽 버튼으로 누르면 다음 메뉴가 나옵니다.

- **{프로젝트 이름}에서 새 Agent**: **+**와 같습니다.
- **IDE에서 열기**: IDE 페이지로 이동합니다. 다른 프로젝트라면 그 프로젝트 자신의 창을 보여 줍니다(열려 있지 않으면 먼저 엽니다).
- **사이드바에서 제거**: 프로젝트를 사이드바에서 뺍니다. 파일이나 대화는 삭제되지 않습니다. 이 창 자신의 프로젝트는 제거할 수 없습니다.

## 대화 메뉴 {#menu}

사이드바에서 대화를 마우스 오른쪽 버튼으로 누릅니다. 메뉴는 그 대화가 어느 프로젝트의 것인지에 따라 달라집니다.

**이 창의 프로젝트의 대화:**

- **오른쪽에서 열기**: 오른쪽 패널의 탭으로 엽니다.
- **대화 인용**: 현재 입력창에 이 대화를 넣습니다. AI는 필요할 때 읽습니다.
- **이름 변경**, **상단 고정**(고정되어 있으면 **고정 해제**), **즐겨찾기**(즐겨찾기 상태면 **즐겨찾기 해제**).
- **채팅 내보내기**: 이 창의 대화에만 있습니다.
- **삭제**.

**다른 프로젝트의 대화:**

- **오른쪽에서 열기**와 **대화 인용**.
- **해당 창에서 계속**: 그 프로젝트 자신의 창에서 이어 갑니다.
- **이름 변경**, **상단 고정**, **즐겨찾기**, **삭제**: 모두 그 프로젝트 안에서 처리됩니다.
- **채팅 내보내기**는 없습니다.

## 서브에이전트 {#subagents}

서브에이전트는 다른 대화가 시작한 대화입니다. 시작한 대화 아래에, 시작된 순서대로 한 단계 들여 써서 나열됩니다.

- 서브에이전트가 있는 대화 줄에는 버튼이 있어 누르면 **하위 에이전트 접기**가 됩니다. 접으면 개수가 표시되고, 다시 누르면(**하위 에이전트 펼치기**) 펼쳐집니다. 접고 펼친 상태는 기억됩니다.
- 서브에이전트를 클릭하면 오른쪽 패널의 탭으로 열립니다.

## 다른 프로젝트의 대화 {#other}

사이드바에서 다른 프로젝트의 대화를 클릭하면 메인 영역에 표시됩니다. 무엇을 했는지 읽을 수 있습니다. 이어 가려면 여기 입력창에 쓰기만 하면 됩니다. 대화는 그 프로젝트에서 이어지고, 진행 상황이 페이지에 실시간으로 표시됩니다.

여기서 하는 다음 작업은 모두 그 프로젝트에서 실행됩니다.

- 메시지 보내기와 이전 메시지 수정.
- AI가 하려는 작업의 승인 또는 거부, 그리고 **중지**.
- 변경 막대의 **전체 유지**와 **전체 취소**.

그 프로젝트의 창이 열려 있지 않으면 Breezell이 화면에 표시하지 않고 백그라운드에서 엽니다. 한동안 사용하지 않으면 저절로 닫힙니다. 실행 중인 것이 없고, 보고 있는 사람이 없고, 저장하지 않은 파일이 없을 때입니다. 그 창을 보고 싶다면 프로젝트 줄을 마우스 오른쪽 버튼으로 눌러 **IDE에서 열기**를 선택하세요.

AI 답변에 있는 파일 링크는 그 프로젝트의 파일을 정확한 줄에서 엽니다.

그 프로젝트 자신의 창에서 이어 가고 싶다면 대화를 마우스 오른쪽 버튼으로 눌러 **해당 창에서 계속**을 선택하세요.

## 오른쪽 패널 {#right}

오른쪽 패널은 IDE와 같은 편집기 영역입니다. 파일, 대화 탭, 내장 브라우저를 나란히 열 수 있습니다.

- 사이드바의 대화를 오른쪽 패널로 끌어다 놓으면 나란히 볼 수 있습니다. 메뉴의 **오른쪽에서 열기**도 됩니다.
- 페이지 위쪽 버튼(**오른쪽 패널 표시** / **오른쪽 패널 숨기기**)으로 숨기거나 다시 표시합니다.
- 사이드바의 가장자리를 끌면 너비를 바꿀 수 있고, 가장자리를 더블클릭하면 기본 너비로 돌아갑니다. 오른쪽 패널의 가장자리도 끌어서 크기를 바꿀 수 있습니다.

## 계정 막대 {#account}

사이드바 맨 아래에 계정 막대가 있습니다.

- 아바타, 이름, 플랜, 잔액(팀 멤버에게는 잔액이 표시되지 않습니다). 누르면 계정 패널이 열립니다.
- 톱니바퀴(**설정**)는 Breezell의 설정을 엽니다.
- **더 보기**(⋯) 메뉴에는 **플랜 관리**, **업데이트**, **피드백 보내기**, **로그아웃**이 있습니다.
- 로그인하지 않았을 때는 **로그인**과 "Breezell 계정에 로그인"이 표시됩니다. 누르면 로그인이 시작됩니다.

## 다중 프로젝트 작업 영역 {#workspaces}

여러 프로젝트를 하나의 창으로 합쳤다면([프로젝트 그룹과 메모리 공유](/ko/project-group) 참고), 이 창의 프로젝트 줄에는 "다중 프로젝트 작업 영역"이 표시되고, 이름 옆에 그 안의 프로젝트들이 나열됩니다.

멤버 프로젝트에서 가져온 대화는 제목에 "[이름]"을 붙이는 대신, 제목 앞에 작은 색 태그로 그 프로젝트를 표시합니다.

## 자동 승인 안내 {#auto-approve}

자동 승인이 켜져 있어도 일부 작업은 확인을 요청하며 멈춥니다. 카드에는 그 이유도 표시됩니다. 예를 들면 "자동 승인이 켜져 있지만, 이 명령은 폴더 전체를 삭제하거나 삭제 범위를 미리 알 수 없어 확인이 필요합니다."와 같습니다. 대상은 다음과 같습니다.

- 폴더 전체를 삭제할 수 있는 명령, 또는 삭제 범위를 미리 알 수 없는 명령.
- AI의 규칙, 스킬, 메모리, MCP 설정 변경.
- 저절로 실행되는 파일(git 설정과 hook, 작업 영역 설정과 작업, 셸 프로필) 변경.
- SSH 키 또는 SSH 설정 변경.
- 작업 영역, 홈 폴더, 작업 영역 밖의 폴더 전체 삭제.

Agents 페이지에서 다른 프로젝트의 대화를 이어 갈 때도 이 확인은 똑같이 나타납니다.

## 현재의 제한 {#limits}

- 다른 프로젝트의 대화에서는 텍스트만 전송됩니다. 첨부한 파일과 이미지는 전송되지 않습니다.
- 다른 프로젝트의 대화에서는 실패한 답변의 **다시 시도** 버튼을 쓸 수 없습니다.
- 이 컴퓨터의 창에서는 SSH 프로젝트의 파일 링크를 열 수 없습니다.
- **상태별**로 정렬하면 다른 프로젝트의 Agent는 작업 중이든 응답 대기든 모두 **기타**에 나열됩니다.
