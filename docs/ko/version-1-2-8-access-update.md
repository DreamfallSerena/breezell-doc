# 1.2.8 버전 이용 방식 변경 안내

Breezell의 장기적이고 안정적인 운영을 위해 Entanglement와 Teams는 1.2.8 버전부터 초대 기반 잠금 해제 방식으로 전환됩니다.

## 잠금 해제 규칙

- **Entanglement 및 Teams:** 새 사용자 5명을 초대하고 모두 등록을 완료하면 잠금이 해제됩니다.
- **기존 유료 사용자:** 초대가 필요하지 않습니다. 관리자에게 문의하여 잠금을 해제하세요.
- **Custom API 플랜 사용자:** 초대가 필요하지 않습니다. 관리자에게 문의하여 잠금을 해제하세요.

## 영향을 받지 않는 기능

- **Agent 모드:** 이번 조정의 영향을 받지 않으며, 계속 정상적으로 사용할 수 있습니다.
- **사용자 지정 API:** 계속 무료로 제공되며, 이번 조정으로 유료화되지 않습니다.

## 조정 범위

이번 조정은 Entanglement와 Teams의 잠금 해제 방식에만 적용됩니다. 그 외 기능은 변경되지 않습니다.

## 감사의 말씀

이해와 지원에 감사드립니다. 기존 사용자 경험에 미치는 영향을 최소화하면서 Breezell을 계속 유지·개선하여 프로젝트를 장기적으로 안정적으로 운영하겠습니다.
