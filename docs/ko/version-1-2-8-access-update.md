# 1.2.8 버전 이용 방식 변경 안내

Breezell의 장기적인 운영을 위해 1.2.8 버전부터 Entanglement와 Teams는 초대를 통해 잠금 해제됩니다.

::: tip 이 페이지의 화면 안내
아래의 Breezell 화면은 Breezell 소스 코드를 바탕으로 HTML로 다시 만든 것입니다. 화면의 텍스트는 이 페이지의 언어를 따릅니다.
:::

## 변경 사항 {#changes}

- **Entanglement와 Teams**는 Breezell 사용자 다섯 명이 초대 링크를 통해 도와주면 잠금 해제됩니다. 잠금 해제는 영구적입니다. [새 사용자 초대 방법](/invite-new-users)을 참고하세요.
- **유료 플랜**에는 두 모드가 모두 포함되어 있으므로 초대가 필요하지 않습니다.
- **Custom API 플랜 사용자**도 초대가 필요하지 않습니다. 모드가 여전히 잠겨 있다면 관리자에게 문의하세요.

잠금이 해제되기 전까지는 모드 메뉴에서 두 모드에 자물쇠가 표시되고, 마우스를 올리면 진행 상황이 나타납니다.

<BzLiaotian tanchu="moshi" moshi="agent" suoding />

잠긴 모드를 선택하면 다음 메시지가 표시됩니다. <BzWenben jian="chatMode.entanglementSendBlocked" />

## 변경되지 않은 사항 {#unchanged}

- **Agent 모드**를 비롯한 다른 모든 모드는 이전처럼 계속 사용할 수 있습니다.
- **사용자 지정 API (BYOK)** 기능은 계속 무료로 제공되며, 이번 변경으로 유료화되지 않습니다. [사용자 지정 API (BYOK)](/custom-api)를 참고하세요.
- 그 밖의 모든 기능은 변경되지 않습니다.

## 감사의 말씀 {#thanks}

이해와 지원에 감사드립니다. 기존 사용자에게 미치는 영향을 최소화하면서, Breezell이 장기적으로 안정적으로 운영될 수 있도록 계속 유지하고 개선해 나가겠습니다.
