# Breezell 1.4.0 업데이트 로그

**출시 시간: 2026-09-26 (미 서부 시간)**

## 신규 기능

### 모델 및 기능

- GLM-5.5 Flash, GLM-5.4, Kimi K4, DeepSeek V4.1 Pro, Muse Spark 1.4 모델 항목 추가.
- Image Studio에서 Hy Image 3.5와 Qwen Image 2.1 지원.

## 인터랙션 및 디자인

- 디자인 미리보기는 고정 색상 대신 현재 에디터 테마와 프로젝트 Design Token을 사용합니다.
- 선언되지 않은 CSS 변수는 실패 대신 안내 정보를 제공합니다.
- Workspace의 `DESIGN.md` 규칙이 workflow 안내에 포함됩니다.
- 확정된 디자인은 `.breezell/design/`에 독립 HTML 파일로 저장됩니다.

## 알림

- 알림 패널을 목록과 상세 보기 구조로 변경했습니다.
- 중요 알림은 상단에 고정됩니다.

## 수정 및 개선

- 새 브랜치 생성 시 기존 대화 내용을 먼저 복사합니다.
- 긴 대화는 점진적으로 로드되어 성능이 개선되었습니다.
- 스트리밍 코드 하이라이트가 증분 업데이트 방식으로 변경되었습니다.
- 대화 삭제 후 데이터베이스 공간을 즉시 정리합니다.
- SCM 기록 목록 캐시로 대량 파일 처리 성능을 개선했습니다.
