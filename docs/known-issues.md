# Known Issues

We have identified the following issues in Breezell version 1.2.8. We are working to resolve them and will share updates as they become available.

## Some conversations may not load

> **Status: Fixed**

This issue has been fixed. Your data and conversation content remain safe and will not be lost.

## Entanglement Mode output formatting

> **Status: Fixed**

This issue has been fixed.

## Unexpected crashes

> **Status: Fixed**

This issue has been fixed.

## Built-in browser displays a blank page

> **Status: Fixed**

This issue has been fixed.

## Analyze mode may expose trailing tags

> **Status: Fixed**

This issue has been fixed.

## Custom context window setting was not applied for Codex models

> **Status: Fixed**

After setting the context window for gpt-5.6-sol to 512K (512,000 tokens), Breezell continued to display a 272K maximum context window in new conversations. Restarting the client or creating a new conversation did not apply the setting.

This issue has been fixed. Breezell now correctly applies and displays the configured custom context window.

## Grok direct login quota display issue

> **Status: Fixed**

This issue has been fixed.

## Automatic compression did not run after switching the context window

> **Status: Fixed**

After switching the context window, automatic compression could fail to trigger, so conversations were not compressed as expected. This issue has been fixed.

## Dropdown menus show native styling and overly narrow borders

> **Status: Fixed**

This issue has been fixed.

## Kimi-series model reasoning-level settings issue

> **Status: Fixed**

This issue has been fixed.

## Chat may stutter when sending messages

> **Status: Fixed**

This issue has been fixed.

We are working to resolve these issues as soon as possible. Thank you for your understanding and patience.
