# Version 1.2.8 Access Update

To support Breezell's long-term operation, Entanglement and Teams will move to invitation-based unlocking starting with version 1.2.8.

## Unlocking rules

- **Entanglement and Teams:** Unlock after five newly invited users complete registration.
- **Existing paid users:** No invitations are required. Contact an administrator to unlock access.
- **Custom API plan users:** No invitations are required. Contact an administrator to unlock access.

## Unchanged access

- **Agent mode:** This adjustment does not affect Agent mode, which remains available as usual.
- **Custom API:** Custom API remains free and will not become paid because of this adjustment.

## Scope of this update

This update changes only how Entanglement and Teams are unlocked. All other features remain unchanged.

## Thank you for your support

Thank you for your understanding and support. We will continue maintaining and improving Breezell so the project can operate reliably over the long term while minimizing the impact on existing users.
