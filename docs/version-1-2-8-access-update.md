# Version 1.2.8 Access Update

To support Breezell's long-term operation, Entanglement and Teams are unlocked by invitation starting with version 1.2.8.

::: tip About the screens on this page
The Breezell screen below is rebuilt in HTML from the Breezell source code. Its text follows the language of this page.
:::

## What changed {#changes}

- **Entanglement and Teams** are unlocked after five Breezell users have assisted you through your invite link. The unlock is permanent. See [How to Invite New Users](/invite-new-users).
- **Paid plans** include both modes; no invitations are needed.
- **Custom API plan users** do not need invitations either. If the modes are still locked for you, contact an administrator.

Until the modes are unlocked, they show a lock in the mode menu, and hovering them shows your progress:

## What did not change {#unchanged}

- **Agent mode** and all other modes stay available as before.
- **Custom API (BYOK)** stays free and does not become paid because of this change. See [Custom API (BYOK)](/custom-api).
- All other features are unchanged.

## Thank you {#thanks}

Thank you for your understanding and support. We will keep maintaining and improving Breezell so that it can run reliably over the long term, while keeping the impact on existing users as small as possible.
