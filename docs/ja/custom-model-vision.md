# カスタムモデルの視覚機能

> マルチモーダル入力に対応していないカスタムモデルに、独立した視覚モデルを通じて画像認識機能を追加します。

## 始める前に

カスタムモデルがマルチモーダル入力に対応していない場合、Breezell 1.2.8 では別のモデルを通じて画像認識機能を利用できます。先に視覚対応モデルを設定してから、画像を理解する必要があるカスタムモデルに割り当ててください。

## モデル設定を開く

1. エディター右上のツールバーにある設定の歯車アイコンをクリックします。
2. メニューで **Breezell Settings** を選択します。
3. 設定サイドバーで **Models** を選択します。

カスタムモデルをまだ設定していない場合は、先に[カスタム API の設定](/ja/custom-api)を完了してください。

## Vision Proxy の設定を開く

1. モデル一覧で、画像認識機能が必要なカスタムモデルを見つけます。
2. そのモデルの小さな目のアイコンをクリックして **Vision Proxy** を開きます。

![モデル一覧で強調表示された Vision Proxy ボタン](/custom-model-vision/open-vision-proxy-settings.png)

## 画像認識モデルを選択する

1. **Vision Proxy** ダイアログで、**Image recognition model** セレクターを開きます。
2. 設定済みで画像認識に対応するモデルを選択します。
3. **Save** をクリックして選択内容を保存します。

![画像認識モデルの選択と Save が強調表示された Vision Proxy ダイアログ](/custom-model-vision/select-vision-recognition-model.png)

## 会話を開始する

会話でそのカスタムモデルを選択し、画像を添付してメッセージを送信します。Breezell は選択した画像認識モデルを使用して、カスタムモデルによる画像の処理を支援します。

![選択した画像認識モデルを通じてカスタムモデルが添付画像を認識する会話画面](/custom-model-vision/custom-model-vision-conversation.png)
