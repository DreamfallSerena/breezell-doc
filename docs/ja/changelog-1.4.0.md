# Breezell 1.4.0 リリースノート

**リリース日時: 2026-09-26（米国太平洋時間）**

## 新機能

### モデルと機能

- GLM-5.5 Flash、GLM-5.4、Kimi K4、DeepSeek V4.1 Pro、Muse Spark 1.4 を追加。
- Image Studio が Hy Image 3.5 と Qwen Image 2.1 に対応。

## インタラクションとデザイン

- デザインプレビューは固定カラーパレットではなく、エディターのテーマとプロジェクトの Design Token を使用します。
- 未定義の CSS 変数はエラーではなく説明を返します。
- Workspace の `DESIGN.md` が workflow の指示に反映されます。
- 確定したデザインは `.breezell/design/` に独立した HTML として保存されます。

## 通知

- 通知パネルを左側リスト、右側詳細表示に変更しました。
- 重要な通知は上部に固定されます。

## 修正と改善

- 新しいブランチ作成時に元の会話内容をコピーします。
- 長い会話は段階的に読み込みます。
- ストリーミング中のコードハイライトを増分更新方式に改善しました。
- 会話削除後、データベース領域を即時整理します。
- SCM キャッシュにより大量ファイル処理を高速化しました。
