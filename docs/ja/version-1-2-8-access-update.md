# バージョン 1.2.8 の利用方法に関するお知らせ

Breezell の長期的で安定した運営を維持するため、Entanglement と Teams はバージョン 1.2.8 から招待によるアンロック方式へ移行します。

## アンロックの条件

- **Entanglement と Teams：** 新規ユーザーを 5 名招待し、全員が登録を完了するとアンロックされます。
- **既存の有料ユーザー：** 招待は不要です。管理者に連絡してアンロックしてください。
- **Custom API プランのユーザー：** 招待は不要です。管理者に連絡してアンロックしてください。

## 変更されない機能

- **Agent モード：** 今回の調整の対象外であり、これまでどおり利用できます。
- **カスタム API：** 引き続き無料で利用でき、今回の調整によって有料化されることはありません。

## 今回の調整の対象

今回の調整は、Entanglement と Teams のアンロック方法のみに適用されます。その他の機能に変更はありません。

## ご理解とご支援への感謝

ご理解とご支援に感謝します。既存ユーザーへの影響をできる限り抑えながら、Breezell を継続的に保守・改善し、プロジェクトを長期的かつ安定して運営していきます。
