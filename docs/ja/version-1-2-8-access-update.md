# バージョン 1.2.8 の利用方法に関するお知らせ

Breezell の長期的な運営を支えるため、バージョン 1.2.8 から Entanglement と Teams は招待によって解除する仕組みになりました。

::: tip このページの画面について
以下の Breezell の画面は、Breezell のソースコードをもとに HTML で再現したものです。表示テキストはこのページの言語に従います。
:::

## 変更点 {#changes}

- **Entanglement と Teams** は、招待リンクから 5 人の Breezell ユーザーに協力してもらうと解除されます。解除は永久に有効です。[新規ユーザーを招待する方法](/invite-new-users) を参照してください。
- **有料プラン** には両方のモードが含まれているため、招待は必要ありません。
- **Custom API プランのユーザー** も招待は必要ありません。それでもモードがロックされている場合は、管理者にお問い合わせください。

モードが解除されるまでは、モードメニューに鍵アイコンが表示され、マウスを合わせると進捗が表示されます。

<BzLiaotian tanchu="moshi" moshi="agent" suoding />

ロックされたモードを選ぶと、次のように表示されます：<BzWenben jian="chatMode.entanglementSendBlocked" />

## 変更されないこと {#unchanged}

- **Agent モード** をはじめ、その他のモードはこれまでどおり利用できます。
- **カスタム API（BYOK）** は引き続き無料で、今回の変更によって有料になることはありません。[カスタム API（BYOK）](/custom-api) を参照してください。
- その他の機能に変更はありません。

## ご理解とご支援への感謝 {#thanks}

ご理解とご支援に感謝いたします。既存ユーザーへの影響をできる限り小さく抑えながら、Breezell が長期にわたって安定して動作するよう、今後も保守と改善を続けていきます。
