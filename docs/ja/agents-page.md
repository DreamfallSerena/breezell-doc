# Agents ページ

Agents ページは Breezell のページのひとつで、**すべてのプロジェクトの会話を 1 か所にまとめます**。左側のサイドバーには各プロジェクトとその会話が並び、右側は IDE と同じエディター領域で、ファイル、会話、内蔵ブラウザーを並べて開けます。プロジェクトごとにウィンドウを開かなくても、どの AI が何をしているか、どれがあなたの返答を待っているかが分かり、そのままここで会話を続けられます。

このガイドは、Agents ページが登場した Breezell 1.4.58 について説明します。ページの切り替え、サイドバーの各部分、プロジェクトの追加、会話のメニュー、ほかのプロジェクトの会話の扱い、右側、アカウントバー、複数プロジェクトのワークスペース、現在の制限を扱います。

## ページを開く {#open}

タイトルバーに切り替えがあります：**Agents | IDE | Box**。**Agents** をクリックするとこのページ、**IDE** をクリックするといつものエディター、**Box** をクリックするとモデル、機能オプション、Breezell のすべての設定のページに移ります。

- 新しいウィンドウは、初期設定では Agents ページで開きます。
- ウィンドウを閉じてもう一度開くと、閉じたときに表示していたページ（Agents、IDE、Box）に戻ります。
- ファイルを表示するために開いたウィンドウ（たとえば Breezell でファイルを開いたとき）は、必ず IDE で開きます。
- 新しいウィンドウを Agents ページで開きたくない場合は、ページ右上の**その他**（⋯）をクリックして、**ウィンドウを開いたときにこのページを表示**のチェックを外します。**設定**で「Agents page」を検索し、「Open new windows on the Agents page」のチェックを外すこともできます（この設定の文言は英語です）。

| 用語 | 意味 |
| --- | --- |
| プロジェクト | フォルダー（または複数フォルダーのワークスペース）。このパソコン、WSL、SSH のいずれにもあります。 |
| Agent | 1 つの会話。サイドバーの会話はすべて Agent です。 |
| サブエージェント | ほかの会話が始めた会話。始めた会話の下に並びます。 |
| 右側 | ページ右側のエディター領域。ファイル、会話のタブ、内蔵ブラウザーが並びます。 |

## サイドバー {#sidebar}

サイドバーの上部には 4 つの入口があります。

- **新しいチャット**：このウィンドウのプロジェクトで新しい会話を始めます。
- **Box**：Box ページに切り替えます。
- **カスタマイズ**：ルール、メモリ、スキル。
- 検索ボタン（**会話を検索**）：検索ボックスを開きます。キーワードを入力すると会話が絞り込まれます。`Esc` で消去して閉じます。

その下が**エージェント**セクションで、会話をプロジェクトごとに並べます。

- 最初はこのウィンドウのプロジェクトです。続いて、会話のあるほかのプロジェクトと、自分で追加したプロジェクトが、最近使った順に並びます。
- プロジェクトの行には、環境（例：`WSL: ubuntu`、`SSH: host`）、最後に使った時刻、**+** が表示されます。**+**（ツールチップ「{プロジェクト名} で新しい Agent」）を押すと、そのプロジェクトで新しい会話を始めます。
- 会話の前の丸い点は状態を表します：**作業中**、**あなたの返答待ち**、または待機中（目印なし）。点の隣には、その会話の経過時間が「たった今」「5分」「2時間」のように表示されます。
- プロジェクトの会話が多いときは、**さらに表示**を押して広げます。

サイドバーを隠すには、左上のボタン（**サイドバーの切り替え**）を押します。隠している間は、ページの上部にもう一度開くボタンと、**新しいチャット**ボタンが表示されます。

## 並べ方 {#group-by}

**エージェント**の見出しの隣にあるフィルターのボタン（**並べ方**）で、3 通りから選べます。

- **プロジェクト別**：プロジェクトごとに 1 グループ。初期設定です。
- **時間順**：すべての会話を新しい順に 1 つのリストで表示し、各行にどのプロジェクトの会話かを示します。
- **状態別**：**作業中**、**返信待ち**、**その他**の 3 グループ。どの Agent があなたを待っているかがひと目で分かります。

## プロジェクトを追加する {#add}

サイドバーには、会話のあるプロジェクトが表示されます。フォルダーを最初から表示したいときは、**エージェント**の見出しの隣にあるフォルダーのボタン（**プロジェクトを追加…**）を押します。

- 選べる場所がひとつだけなら、すぐにフォルダーの選択画面が開き、複数のフォルダーをまとめて選べます。
- 選べる場所が複数あるときは、先にメニューが出ます。このパソコンのウィンドウでは **Windows のフォルダーを追加…**、WSL があれば **WSL のフォルダーを追加…** も出ます。WSL や SSH のウィンドウでは **{環境名} のフォルダーを追加…** です。以前使った環境（たとえば SSH ホスト）は **{環境名} のプロジェクトを追加…** として並び、そこにあるプロジェクトにチェックを入れるか、フルパスを入力できます。いちばん下は**別のホストに接続…**です。

追加したプロジェクトは、削除するまでサイドバーに残ります。

プロジェクトの行を右クリックすると、次のメニューが出ます。

- **{プロジェクト名} で新しい Agent**：**+** と同じです。
- **IDE で開く**：IDE ページに移ります。ほかのプロジェクトの場合は、そのプロジェクト自身のウィンドウを表示します（開いていなければ先に開きます）。
- **サイドバーから削除**：プロジェクトをサイドバーから外します。ファイルや会話は削除されません。このウィンドウ自身のプロジェクトは外せません。

## 会話のメニュー {#menu}

サイドバーの会話を右クリックします。メニューは、その会話がどのプロジェクトのものかで変わります。

**このウィンドウのプロジェクトの会話：**

- **右側で開く**：右側のタブとして開きます。
- **会話を参照**：現在の入力欄に会話を入れます。AI は必要なときに読みます。
- **名前を変更**、**ピン留め**（ピン留め済みなら**ピン留めを解除**）、**お気に入りに追加**（追加済みなら**お気に入りから削除**）。
- **チャットをエクスポート**：このウィンドウの会話だけにあります。
- **削除**。

**ほかのプロジェクトの会話：**

- **右側で開く**と**会話を参照**。
- **そのウィンドウで続ける**：そのプロジェクト自身のウィンドウで続けます。
- **名前を変更**、**ピン留め**、**お気に入りに追加**、**削除**。すべてそのプロジェクトの中で行われます。
- **チャットをエクスポート**はありません。

## サブエージェント {#subagents}

サブエージェントは、ほかの会話が始めた会話です。始めた会話の下に、始まった順に 1 段インデントして並びます。

- サブエージェントのある会話の行にはボタンがあり、押すと**サブエージェントをたたむ**ことができます。たたむと数が表示され、もう一度押す（**サブエージェントを表示**）と広がります。たたんだか広げたかは記憶されます。
- サブエージェントをクリックすると、右側のタブとして開きます。

## ほかのプロジェクトの会話 {#other}

サイドバーでほかのプロジェクトの会話をクリックすると、メイン領域に表示されます。何をしたかを読めます。続けるには、ここの入力欄に書くだけです。会話はそのプロジェクトで続き、進み具合がページにリアルタイムで表示されます。

ここで行う次の操作は、すべてそのプロジェクトで実行されます。

- メッセージの送信と、以前のメッセージの編集。
- AI がしようとすることの承認や拒否、そして**停止**。
- 変更バーの**すべて保持**と**すべて破棄**。

そのプロジェクトのウィンドウが開いていないときは、Breezell が画面に出さずにバックグラウンドで開きます。しばらく使われないと自動で閉じます。実行中のものがなく、誰も見ておらず、保存していないファイルもないときです。そのウィンドウを見たいときは、プロジェクトの行を右クリックして **IDE で開く**を選びます。

AI の返信にあるファイルのリンクは、そのプロジェクトのファイルを正しい行で開きます。

そのプロジェクト自身のウィンドウで続けたいときは、会話を右クリックして**そのウィンドウで続ける**を選びます。

## 右側 {#right}

右側は IDE と同じエディター領域です。ファイル、会話のタブ、内蔵ブラウザーを並べて開けます。

- サイドバーの会話を右側にドラッグすると並べて表示できます。メニューの**右側で開く**でも開けます。
- ページ上部のボタン（**右パネルを表示** / **右パネルを非表示**）で隠したり戻したりできます。
- サイドバーの端をドラッグすると幅を変えられ、端をダブルクリックすると元の幅に戻ります。右側の端もドラッグして大きさを変えられます。

## アカウントバー {#account}

サイドバーの下部にアカウントバーがあります。

- アバター、名前、プランと残高（チームメンバーには残高は表示されません）。クリックするとアカウントのパネルが開きます。
- 歯車（**設定**）で Breezell の設定を開きます。
- **その他**（⋯）のメニューには、**プランを管理**、**アップデート**、**フィードバックを送信**、**ログアウト**があります。
- ログインしていないときは、**ログイン**と「Breezell アカウントにログイン」と表示されます。押すとログインが始まります。

## 複数プロジェクトのワークスペース {#workspaces}

複数のプロジェクトを 1 つのウィンドウに統合している場合（[プロジェクトグループとメモリ共有](/ja/project-group)を参照）、このウィンドウのプロジェクトの行は「複数プロジェクトのワークスペース」と表示され、名前の隣にそこに含まれるプロジェクトが並びます。

メンバーのプロジェクトから持ち込まれた会話には、タイトルに「[名前]」を付ける代わりに、タイトルの前に小さな色付きのタグでそのプロジェクトが表示されます。

## 自動承認の確認 {#auto-approve}

自動承認がオンでも、いくつかの操作は確認を求めて止まります。カードにはその理由も表示されます。たとえば「自動承認はオンですが、このコマンドはフォルダー全体を削除するか、削除範囲を事前に判断できないため、確認が必要です。」のようにです。対象は次のとおりです。

- フォルダー全体を削除するおそれのあるコマンド、または削除範囲を事前に判断できないコマンド。
- AI のルール、スキル、メモリ、MCP 設定の変更。
- 自動的に実行されるファイル（git の設定と hook、ワークスペースの設定とタスク、シェルのプロファイル）の変更。
- SSH キーや SSH 設定の変更。
- ワークスペース、ホームフォルダー、ワークスペース外のフォルダー全体の削除。

Agents ページからほかのプロジェクトの会話を続けているときも、これらの確認は同じように表示されます。

## 現在の制限 {#limits}

- ほかのプロジェクトの会話では、テキストだけが送られます。添付したファイルや画像は送られません。
- ほかのプロジェクトの会話では、失敗した返信の**再試行**ボタンは使えません。
- このパソコンのウィンドウからは、SSH プロジェクトのファイルのリンクは開けません。
- **状態別**で並べると、ほかのプロジェクトの Agent は作業中か返答待ちかにかかわらず、すべて**その他**に並びます。
