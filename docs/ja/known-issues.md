# 既知の問題

以下の問題は Breezell バージョン 1.2.8 で見つかったものです。すべて修正済みです。まだいずれかの問題が発生する場合は、最新バージョンに更新してください。

| 問題 | ステータス | 詳細 |
| --- | --- | --- |
| 一部の会話が読み込まれなかった | 修正済み | データは失われていません。会話とその内容は無事です。 |
| Entanglement の出力形式が正しくなかった | 修正済み | [Entanglement モード](/entanglement-mode-overview) を参照してください。 |
| 予期しないクラッシュ | 修正済み | |
| 内蔵ブラウザーに空白のページが表示された | 修正済み | [Breezell Browser](/dialog-box-overview#browser) を参照してください。 |
| Analyze モードで回答の末尾にタグが残ることがあった | 修正済み | [Analyze](/mode-selection#analyze) を参照してください。 |
| Codex モデルにカスタムのコンテキストウィンドウが適用されなかった | 修正済み | `gpt-5.6-sol` を 512K に設定しても、新しい会話では最大 272K と表示されていました。現在の Breezell は、設定したコンテキストウィンドウを適用して表示します。[Context、Reasoning、Fast](/custom-api#context-reasoning-and-fast) を参照してください。 |
| Grok のサインインで誤ったクォータが表示された | 修正済み | |
| コンテキストウィンドウを切り替えた後に自動圧縮が実行されなかった | 修正済み | 会話は再び想定どおりに圧縮されます。[コンテキストの使用量と圧縮](/dialog-box-overview#context) を参照してください。 |
| ドロップダウンメニューがネイティブのスタイルで表示され、枠線が狭かった | 修正済み | |
| Kimi モデルの推論レベルの設定が機能しなかった | 修正済み | |
| メッセージの送信時にチャットが一時的に固まることがあった | 修正済み | |

このガイドの説明どおりに動作しない場合は、[トラブルシューティング](/troubleshooting) を参照するか、Breezell のバージョンと表示内容を添えてお問い合わせください。
