# 既知の問題

Breezell バージョン 1.2.8 では、以下の問題が確認されています。両方の問題は現在修正中で、今後のアップデートで対応予定です。

## 一部の会話が読み込めない問題

> **ステータス：修正対応中**

現在のバージョンでは、一部の会話が正しく読み込まれない場合があります。データや会話内容が失われることはありません。この問題を解決するアップデートを近日中に公開します。

## Entanglement モードの出力形式

> **ステータス：修正対応中**

Entanglement モードでは、出力形式が正しく表示されない場合があります。この問題も次回のアップデートで修正予定です。
