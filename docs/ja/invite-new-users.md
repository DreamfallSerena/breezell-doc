# 新規ユーザーを招待する方法

Breezell では、アカウント専用の招待リンクを生成して新規ユーザーと共有できます。対象条件を満たす招待ユーザーが登録を完了して招待を承認すると、Entanglement と Teams のアンロック進捗に反映されます。

## 始める前に

Breezell アカウントを用意し、公式サイトにログインしていることを確認してください。

## 公式サイトとプロフィールメニューを開く

1. Breezell 公式サイト [https://breezell.com](https://breezell.com) を開きます。
2. ログインしていない場合は、Breezell アカウントでログインします。
3. ページ右上のプロフィール画像をクリックします。

![プロフィール画像が強調表示された Breezell 公式サイト](/invitation-guide/open-profile-menu.png)

## Profile ページを開く

1. アカウントメニューで **Profile** を見つけます。
2. **Profile** をクリックしてプロフィールページを開きます。

![Profile が強調表示されたアカウントメニュー](/invitation-guide/select-profile.png)

## 招待リンクを生成する

1. Profile ページ左側で **Account** を選択します。
2. **Unlock Entanglement and Teams Modes** セクションを見つけます。
3. **Generate invite link** をクリックします。

![Account ページの Generate invite link ボタン](/invitation-guide/generate-invite-link.png)

::: tip ヒント
アンロック状態を一時的に読み込めない場合は、一度アカウントからログアウトして再度ログインし、Account ページに戻って状態を確認してください。
:::

## 友人に招待を送る

リンクを生成すると、Breezell に次のようなメッセージが表示されます。

```text
Can you help me unlock this? I'm waiting in the Breezell editor.
https://breezell.com/mode-invite/entanglement?token=YOUR_INVITE_TOKEN
```

上記の Token はプレースホルダーです。ご自身のアカウントで生成された完全なメッセージとリンクをコピーして、友人に送ってください。

友人はリンクを開き、登録またはログインして招待を承認できます。対象となる新規ユーザーが必要な登録手続きを完了すると、アンロック進捗に反映されます。
