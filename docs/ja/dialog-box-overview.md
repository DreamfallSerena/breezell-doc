# ダイアログボックスの概要

Breezell のダイアログボックスは、プロンプトの入力、作業モードの選択、モデルの選択、コンテキストの添付、Agent による現在のリクエストの処理方法の制御を行う主な場所です。

このページでは、ダイアログボックスのスクリーンショットに表示されるコントロールについて説明します。

## デフォルトの入力状態

デフォルトの入力状態は、新しいメッセージの通常の開始状態です。プロンプトフィールドと基本的なコントロールを表示したままにします。

![デフォルトの入力状態](/dialog-box/input-default.png)

リクエストを入力し、必要に応じてモードとモデルを選択して、Breezell にメッセージを送信します。

## モードセレクターメニュー

ポインターがモードセレクターメニューを強調しています。このメニューには利用可能な作業モードが表示されます。

![モードセレクターメニュー](/dialog-box/mode-selector.png)

利用できるモードは次のとおりです。

- [**Chat**](/ja/mode-selection#chat)：すばやい質問と回答
- [**Plan**](/ja/mode-selection#plan)：編集前の実装計画
- [**Analyze**](/ja/mode-selection#analyze)：読み取り専用の調査
- [**Entanglement**](/ja/mode-selection#entanglement)：より深い因果推論
- [**Agent**](/ja/mode-selection#agent)：自律的なファイル編集とツールの使用
- [**Teams**](/ja/mode-selection#teams)：複雑なタスクでの並列 AI チームメイト

詳しくは[モードの選択](/ja/mode-selection)を参照してください。必要な自律性と深さに合ったモードを選択します。

## モデルセレクター

ポインターがモデルセレクターを強調しています。セレクターには現在のモデルが表示され、メッセージを送信する前に別の利用可能なモデルへ切り替えられます。

![モデルセレクター](/dialog-box/input-compact-controls.png)

速度、推論、機能特性が異なるモデルを選びたいときに使用します。

## ファイルのアップロード

ポインターがファイルアップロードコントロールを強調しています。

![ファイルアップロードコントロール](/dialog-box/input-model-controls.png)

このコントロールをクリックすると、現在のメッセージを Breezell に送信する前にローカルファイルを添付できます。アップロードしたファイルはリクエストコンテキストの一部になるため、Breezell は回答中にファイルを確認したり参照したりできます。

## ~~高度な探索~~

> **バージョン 1.2.5 以降は非推奨です。** 専用の高度な探索コントロールは利用できなくなりました。より深い調査が必要なリクエストでは、Breezell が関連機能を自動的に呼び出し、アクティブラーニング、広範な調査、より徹底した探索を行います。

![高度な探索コントロール](/dialog-box/input-tools-expanded.png)

## Breezell ブラウザー

ポインターが **Breezell Browser** コントロールを強調しています。

![Breezell Browser コントロール](/dialog-box/input-agent-basic.png)

Breezell Browser は Breezell に組み込まれたブラウザーツールです。ダイアログボックスから離れずにウェブページを開き、オンラインコンテンツを表示し、情報を検索し、AI にウェブコンテンツの取得と分析をさせることができます。

## コンテキスト使用量の内訳

ポインターがコンテキスト使用量インジケーターを強調しています。開くと、現在のコンテキストウィンドウの使用状況を詳しく確認できます。

![コンテキスト使用量の内訳](/dialog-box/context-usage-breakdown.png)

内訳では、システムプロンプト、ツール、ルール、メモリ、Skills、MCP、サブエージェント、会話内容などのカテゴリに分けて使用量を表示します。セッションのどの部分が最も多くのトークンを消費しているかを確認できます。

## コンテキストの手動圧縮

ポインターがコンテキストパネルの **Manual compress** コントロールを強調しています。この操作は以前の会話内容を要約し、コンテキスト使用量を減らしながらセッションに役立つ情報を保持します。

![手動圧縮が表示されたコンテキストパネル](/dialog-box/context-manual-compress.png)

手動圧縮は長い会話で便利です。特にコンテキストウィンドウが大きくなっても同じセッションを続けたい場合に適しています。

## クイックフレーズ

ポインターが入力トレイの **Quick Phrases** ボタンを強調しています。クイックフレーズを使うと、よく使用するプロンプトや指示を保存し、毎回入力せずに新しいメッセージで再利用できます。

![入力トレイの Quick Phrases ボタン](/dialog-box/quick-phrases-button.png)

**Quick Phrases** を開くと、保存したフレーズを表示・整理できます。**Add** から新しいフレーズを作成します。左側の **All phrases** には保存済みの全フレーズが表示されます。よく使うフレーズは右側の **Favorites** にドラッグして登録し、左側へ戻すとお気に入りから解除できます。

保存したフレーズを選択すると、現在の入力欄に挿入されます。メッセージを送信する前に内容を編集することもできます。

![クイックフレーズ管理画面](/dialog-box/quick-phrases-manager.png)

## MCP サーバー

ポインターが入力トレイの **MCP** ボタンを強調しています。開くと、設定済みの MCP サーバーを確認し、各サーバーを Breezell で使用できるかどうかを切り替えられます。

![MCP サーバーのコントロール](/dialog-box/mcp-server-controls.png)

各サーバーの行には次の操作があります。

- **呼び出し矢印：** 現在の入力欄に `/mcp:<server-name>` を挿入します。この参照を含むリクエストを送信すると、AI が選択した MCP サーバーを呼び出せます。
- **オン／オフスイッチ：** 既存の MCP サーバーを有効または無効にします。無効なサーバーは、再び有効にするまで AI から利用できません。
- **ヘルスインジケーター：** 緑の点は MCP サーバーが接続済みで正常であることを示します。赤の点は利用できないか異常な状態であることを示すため、呼び出す前に設定やプロセスを確認してください。

![入力欄に挿入された MCP 参照](/dialog-box/mcp-invocation-reference.png)

## Skills（スキル）

ポインターが入力トレイの **Skills** ボタンを強調しています。開くと、Breezell が使用できるスキルを管理できます。

![組み込みスキルのパネル](/dialog-box/skills-built-in.png)

スキルは次の 2 つのタブに分かれています。

- **Built-in：** Breezell に標準搭載されている公式スキルです。個人スキルを作成・設定しなくても利用できます。
- **My Skills：** 自分で設定または作成したスキルです。

![My Skills パネル](/dialog-box/skills-my-skills.png)

どちらのタブのスキルも個別に操作できます。

- **呼び出し矢印：** 現在の入力欄に `@<skill-name>` を挿入します。このメンションを含むリクエストを送信すると、AI が選択したスキルを呼び出せます。
- **オン／オフスイッチ：** スキルを有効または無効にします。無効なスキルは、再び有効にするまで AI から利用できません。

![入力欄に挿入されたスキルのメンション](/dialog-box/skill-invocation-reference.png)

## メッセージ容量

ポインターが入力トレイの **Message Capacity** ボタンを強調しています。メッセージ容量は、保存済みの会話が使用しているローカルストレージを分析します。モデルのコンテキストウィンドウや、アプリケーションが現在使用しているメモリの表示ではありません。

![Message Capacity ボタン](/dialog-box/message-capacity-button.png)

ダッシュボードでは次の情報と操作を利用できます。

- **範囲と期間：** 現在のワークスペースまたはすべてのワークスペースを選択し、過去 7 日、30 日、90 日の使用状況を確認できます。
- **現在の使用量と推移：** 合計使用量、選択期間中の変化、ストレージ増加のグラフを表示します。
- **ストレージの内訳：** メッセージ内容、画像と添付ファイル、ツール結果、チェックポイントを比較できます。破線は回収可能な容量を示します。
- **概要指標：** 会話数、メッセージ数、最大の会話、回収可能な容量を確認できます。
- **会話の確認：** 会話を検索、並べ替え、絞り込み、選択できます。各行にはメッセージ数、保存容量、主な保存データの種類が表示され、進行中またはキューに入っている会話も明示されます。
- **安全なクリーンアップ：** パネルが回収可能と判断したストレージを整理します。実行前に、現在の範囲、フィルター、選択内容を確認してください。

![メッセージ容量ダッシュボード](/dialog-box/message-capacity-dashboard.png)

## キャッシュヒット

ポインターは入力トレイの **Cache Hit（キャッシュヒット）** ボタンを示しています。**Cache Broadcast** パネルでは、現在のチャットまたはワークスペースにおけるプロバイダーのプロンプトキャッシュ再利用状況を確認できます。これはリクエストキャッシュの統計であり、会話のローカル保存容量やモデルのコンテキスト容量とは別のものです。

![キャッシュヒットボタン](/dialog-box/cache-hit-button.png)

パネルでは、次の情報と操作を利用できます。

- **集計範囲：** 現在のチャットとワークスペース全体を切り替えられます。
- **ヒット率の概要：** 今日、昨日、通算の記録ターン数、ヒット率、キャッシュ読み取り量を比較できます。
- **トークン内訳：** 入力トークン、キャッシュ読み取り、キャッシュ書き込み、出力トークンを確認できます。キャッシュ読み取りは、再処理せずキャッシュから再利用された入力トークンです。
- **節約量の推定：** 節約された入力トークン相当量と、定価を基にした推定節約額を表示します。これは参考値であり、実際の請求額はプロバイダー、モデル、ルートによって異なる場合があります。
- **ターンごとの詳細：** 各ターンのプロバイダー、モデル、推論・速度設定、ヒット率、時刻、所要時間を確認できます。ターンを選択すると、その入力、キャッシュ読み取り、キャッシュ書き込み、出力の合計が表示されます。
- **推移：** グラフで古いリクエストから新しいリクエストまでのヒット率の変化を確認できます。
- **操作：** サマリーをコピーしたり、選択中の集計範囲の統計をクリアしたりできます。

![Cache Broadcast パネル](/dialog-box/cache-hit-dashboard.png)

プロバイダーのキャッシュは一時的です。長時間のアイドル状態、再起動、モデル・速度・バックエンドルートの変更後はヒット率が 0% になることがありますが、その後のリクエストによって再びキャッシュが準備されます。


## メンションメニュー

ポインターがメンションメニューを開くためのクイックコンテキスト領域を強調しています。メンションメニューでは、現在のメッセージにファイル、フォルダー、MCP ツール、Skills を追加できます。

![Breezell ダイアログボックスのメンションメニュー](/dialog-box/mention-menu.png)

リクエストが特定のワークスペースコンテンツや外部機能に依存するときに使用します。適切なコンテキストを追加すると、回答前に何を確認・使用すべきかを Breezell が理解しやすくなります。

## 使用上のヒント

- リクエストが特定のプロジェクト内容に依存する場合は、ファイルまたはフォルダーのコンテキストを追加します。
- Agent はデフォルトモードであり、ほとんどのタスクに推奨される自動ワークフローです。
- 先に計画する、編集せずに分析するといった特定のワークフローが必要な場合のみモードを変更します。
- コンテキスト圧縮は自動的に実行されます。厳密な手動制御を好む場合や特別な要件がある場合のみ、手動圧縮を使用してください。
- 正確さ、速度、推論の深さが重要な場合は、選択したモデルを確認してください。
