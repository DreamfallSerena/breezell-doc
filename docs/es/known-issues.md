# Problemas conocidos

Hemos identificado los siguientes problemas en la versión actual de Breezell. Se resolverán en una próxima actualización.

## Algunas conversaciones pueden no cargar

En la versión actual, algunas conversaciones pueden no cargarse correctamente. Tus datos y el contenido de las conversaciones permanecen seguros y no se perderán. Publicaremos pronto una actualización para resolver este problema.

## Formato de salida del modo Entanglement

En el modo Entanglement, el formato de salida puede mostrarse incorrectamente en ocasiones. Este problema también se corregirá en la próxima actualización.

## Gracias por tu paciencia

Estamos trabajando para resolver estos problemas lo antes posible. Gracias por tu comprensión y paciencia.
