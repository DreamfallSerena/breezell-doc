# Breezell 1.4.0 更新日志

**发布时间：2026-09-26（美西时间）**

## 新增

### 模型与能力

- 预新增模型：GLM-5.5 Flash、GLM-5.4、Kimi K4、DeepSeek V4.1 Pro、Muse Spark 1.4。
- Image Studio 支持 Hy Image 3.5 与 Qwen Image 2.1。

## 交互与设计

- 方案预览现在使用编辑器当前主题和项目 Design Token，不再使用固定色板。
- 未声明的 CSS 变量会返回说明，而不是直接失败。
- 工作区存在 `DESIGN.md` 时，会自动加入流程提示。
- 方案确认后会保存到 `.breezell/design/` 独立 HTML 文件。
- 工具结果统一引用规格、计划和实现来源，减少设计与最终实现偏差。

## 通知

- 通知面板改为左侧列表、右侧详情。
- 重要通知置顶。
- 列表和详情区域独立滚动。

## 修复与优化

- 新建分支前复制原会话正文。
- 长对话改为渐进加载，减少内存占用。
- 流式代码高亮改为增量更新。
- 删除会话后立即压缩数据库并释放空间。
- SCM 历史列表缓存变更路径，提升大量文件场景性能。
- 设置、语言和 OAuth 状态减少无效重新渲染。
