# Известные проблемы

Эти проблемы были обнаружены в Breezell версии 1.2.8. Все они исправлены; если вы всё ещё сталкиваетесь с какой-либо из них, обновитесь до последней версии.

| Проблема | Статус | Подробности |
| --- | --- | --- |
| Некоторые диалоги не загружались | Исправлено | Данные не были потеряны: диалоги и их содержимое в безопасности. |
| Вывод Entanglement форматировался неправильно | Исправлено | См. [Режим Entanglement](/entanglement-mode-overview). |
| Неожиданные сбои | Исправлено | |
| Встроенный браузер показывал пустую страницу | Исправлено | См. [Breezell Browser](/dialog-box-overview#browser). |
| В режиме Analyze в конце ответа могли оставаться лишние теги | Исправлено | См. [Analyze](/mode-selection#analyze). |
| Пользовательское окно контекста не применялось к моделям Codex | Исправлено | После того как для `gpt-5.6-sol` было задано окно 512K, новые диалоги всё равно показывали максимум 272K. Теперь Breezell применяет и показывает настроенное окно. См. [Context, Reasoning и Fast](/custom-api#context-reasoning-and-fast). |
| При входе в Grok отображалась неверная квота | Исправлено | |
| Автоматическое сжатие не запускалось после переключения окна контекста | Исправлено | Диалоги снова сжимаются как положено. См. [Использование и сжатие контекста](/dialog-box-overview#context). |
| Выпадающие меню отображались в нативном стиле и с узкими границами | Исправлено | |
| Настройки уровня рассуждения у моделей Kimi не работали | Исправлено | |
| Чат мог подтормаживать при отправке сообщений | Исправлено | |

Если что-то работает не так, как описано в этом руководстве, см. [Устранение неполадок](/troubleshooting) или свяжитесь с нами и укажите версию Breezell и то, что вы видите.

Спасибо за терпение и за ваши сообщения о проблемах.
