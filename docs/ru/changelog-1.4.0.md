# Breezell 1.4.0 — журнал изменений

**Дата выпуска: 26.09.2026 (тихоокеанское время США)**

## Новое

### Модели и возможности

- Добавлены модели: GLM-5.5 Flash, GLM-5.4, Kimi K4, DeepSeek V4.1 Pro и Muse Spark 1.4.
- Image Studio теперь поддерживает Hy Image 3.5 и Qwen Image 2.1.

## Интерфейс и дизайн

- Предпросмотр решений использует текущую тему редактора и Design Token проекта.
- Необъявленные CSS-переменные теперь возвращают подсказки вместо ошибки.
- Правила из `DESIGN.md` добавляются в workflow подсказки Workspace.
- Подтверждённые дизайны сохраняются в `.breezell/design/` как отдельные HTML-файлы.

## Уведомления

- Панель уведомлений переработана: список слева, детали справа.
- Важные уведомления закрепляются сверху.

## Исправления и улучшения

- При создании ветки сначала копируется содержимое текущего диалога.
- Длинные диалоги загружаются постепенно.
- Подсветка кода в потоке обновляется постепенно.
- После удаления диалогов база данных сразу освобождает место.
- Кэширование SCM улучшает работу с большим количеством изменённых файлов.
