# Обзор диалогового окна

Диалоговое окно Breezell — основное место, где вы пишете подсказки, выбираете рабочий режим, модель и контекст, а также управляете способом обработки текущего запроса агентом.

На этой странице описаны видимые элементы управления, показанные на снимках диалогового окна.

## Состояние ввода по умолчанию

Состояние ввода по умолчанию — обычная отправная точка для нового сообщения. В нём остаются видимыми поле подсказки и основные элементы управления.

![Состояние ввода по умолчанию](/dialog-box/input-default.png)

Введите запрос, при необходимости выберите режим и модель, затем отправьте сообщение в Breezell.

## Меню выбора режима

Указатель выделяет меню выбора режима. В этом меню перечислены доступные рабочие режимы.

![Меню выбора режима](/dialog-box/mode-selector.png)

Доступны следующие режимы:

- [**Chat**](/ru/mode-selection#chat) для быстрых вопросов и ответов
- [**Plan**](/ru/mode-selection#plan) для планирования реализации перед редактированием
- [**Analyze**](/ru/mode-selection#analyze) для исследования в режиме только чтения
- [**Entanglement**](/ru/mode-selection#entanglement) для более глубокого причинно-следственного рассуждения
- [**Agent**](/ru/mode-selection#agent) для автономного редактирования файлов и использования инструментов
- [**Teams**](/ru/mode-selection#teams) для параллельных ИИ-коллег в сложных задачах

Подробнее см. в разделе [Выбор режима](/ru/mode-selection). Выберите режим, соответствующий необходимому уровню автономности и глубины.

## Выбор модели

Указатель выделяет выбор модели. Здесь показана текущая модель и можно переключиться на другую доступную модель перед отправкой сообщения.

![Выбор модели](/dialog-box/input-compact-controls.png)

Используйте этот элемент, если хотите выбрать модель с другими характеристиками скорости, рассуждений или возможностей.

## Загрузка файлов

Указатель выделяет элемент управления загрузкой файлов.

![Элемент загрузки файлов](/dialog-box/input-model-controls.png)

Нажмите этот элемент, чтобы прикрепить локальные файлы к текущему сообщению перед отправкой в Breezell. Загруженные файлы становятся частью контекста запроса, поэтому Breezell может проверять их или обращаться к ним при ответе.

## ~~Расширенное исследование~~

> **Устарело после версии 1.2.5.** Специальный элемент управления расширенным исследованием больше недоступен. Если запрос требует более глубокого исследования, Breezell автоматически вызывает соответствующие возможности для активного обучения, более широкого анализа и тщательного изучения.

![Элемент управления расширенным исследованием](/dialog-box/input-tools-expanded.png)

## Браузер Breezell

Указатель выделяет элемент **Breezell Browser**.

![Элемент Breezell Browser](/dialog-box/input-agent-basic.png)

Breezell Browser — встроенный браузерный инструмент Breezell. С его помощью можно открывать веб-страницы, просматривать онлайн-содержимое, искать информацию и помогать ИИ получать и анализировать веб-содержимое, не покидая диалоговое окно.

## Разбивка использования контекста

Указатель выделяет индикатор использования контекста. При открытии отображается подробная разбивка использования текущего контекстного окна.

![Разбивка использования контекста](/dialog-box/context-usage-breakdown.png)

Использование разделяется на такие категории, как системный промпт, инструменты, правила, память, навыки, MCP, субагенты и содержимое разговора. Это помогает понять, какие части сеанса потребляют больше всего токенов.

## Ручное сжатие контекста

Указатель выделяет элемент **Manual compress** на панели контекста. Это действие суммирует более раннее содержимое разговора, чтобы сохранить полезную информацию и одновременно уменьшить использование контекста.

![Панель контекста с ручным сжатием](/dialog-box/context-manual-compress.png)

Ручное сжатие полезно во время длинных разговоров, особенно когда контекстное окно становится большим, но вы хотите продолжить тот же сеанс.

## Быстрые фразы

Указатель выделяет кнопку **Quick Phrases** на панели ввода. Быстрые фразы позволяют сохранять часто используемые промпты или инструкции и повторно использовать их в новых сообщениях без повторного ввода.

![Кнопка Quick Phrases на панели ввода](/dialog-box/quick-phrases-button.png)

Откройте **Quick Phrases**, чтобы просматривать и упорядочивать сохраненные фразы. Используйте **Add**, чтобы создать фразу. На панели **All phrases** отображаются все сохраненные фразы. Перетащите часто используемую фразу на панель **Favorites** справа, чтобы добавить ее в избранное. Перетащите ее обратно, чтобы удалить из избранного.

Выберите сохраненную фразу, чтобы вставить ее в текущее поле ввода. Перед отправкой сообщения текст можно отредактировать.

![Окно управления быстрыми фразами](/dialog-box/quick-phrases-manager.png)

## Серверы MCP

Указатель выделяет кнопку **MCP** на панели ввода. Откройте ее, чтобы просмотреть настроенные серверы MCP и управлять их доступностью для Breezell.

![Элементы управления серверами MCP](/dialog-box/mcp-server-controls.png)

В каждой строке сервера доступны следующие элементы:

- **Стрелка вызова:** вставляет `/mcp:<имя-сервера>` в текущее поле ввода. Отправьте запрос с этой ссылкой, чтобы ИИ мог вызвать выбранный сервер MCP.
- **Переключатель:** включает или отключает существующий сервер MCP. Отключенный сервер недоступен ИИ, пока вы не включите его снова.
- **Индикатор состояния:** зеленая точка означает, что сервер MCP подключен и исправен. Красная точка означает, что сервер недоступен или работает некорректно; перед вызовом проверьте его конфигурацию или процесс.

![Ссылка MCP, вставленная в поле ввода](/dialog-box/mcp-invocation-reference.png)

## Навыки

Указатель выделяет кнопку **Skills** на панели ввода. Откройте ее, чтобы управлять навыками, доступными Breezell.

![Панель встроенных навыков](/dialog-box/skills-built-in.png)

Навыки разделены на две вкладки:

- **Built-in:** официальные навыки, встроенные в Breezell. Они доступны без создания или настройки личного навыка.
- **My Skills:** навыки, которые вы настроили или создали самостоятельно.

![Панель My Skills](/dialog-box/skills-my-skills.png)

Навыками на обеих вкладках можно управлять по отдельности:

- **Стрелка вызова:** вставляет `@<имя-навыка>` в текущее поле ввода. Отправьте запрос с этим упоминанием, чтобы ИИ мог вызвать выбранный навык.
- **Переключатель:** включает или отключает навык. Отключенный навык недоступен ИИ, пока вы не включите его снова.

![Упоминание навыка, вставленное в поле ввода](/dialog-box/skill-invocation-reference.png)

## Объем сообщений

Указатель выделяет кнопку **Message Capacity** на панели ввода. Раздел «Объем сообщений» анализирует локальное хранилище, занятое сохраненными разговорами. Это отчет о хранилище, а не показатель контекстного окна модели или текущего использования оперативной памяти приложением.

![Кнопка Message Capacity](/dialog-box/message-capacity-button.png)

Панель предоставляет следующие возможности:

- **Область и период:** переключение между текущим и всеми рабочими пространствами, а также просмотр данных за последние 7, 30 или 90 дней.
- **Текущее использование и динамика:** общий объем занятого хранилища, его изменение за выбранный период и график роста.
- **Разбивка хранилища:** сравнение содержимого сообщений, изображений и вложений, результатов инструментов и контрольных точек. Пунктирная линия показывает объем, который можно освободить.
- **Сводные показатели:** количество разговоров и сообщений, размер самого крупного разговора и объем освобождаемого пространства.
- **Просмотр разговоров:** поиск, сортировка, фильтрация и выбор разговоров. В каждой строке отображаются количество сообщений, занимаемый объем и основной тип данных; активные разговоры и разговоры в очереди обозначаются отдельно.
- **Безопасная очистка:** освобождает хранилище, которое панель считает доступным для очистки. Перед запуском проверьте выбранную область, фильтры и элементы.

![Панель объема сообщений](/dialog-box/message-capacity-dashboard.png)

## Попадания в кэш

Указатель выделяет кнопку **Cache Hit (Попадания в кэш)** на панели ввода. Панель **Cache Broadcast** показывает, насколько эффективно кэш промптов провайдера повторно используется в текущем чате или рабочем пространстве. Это статистика кэша запросов, не связанная с локальным хранилищем сохраненных диалогов или объемом контекста модели.

![Кнопка попаданий в кэш](/dialog-box/cache-hit-button.png)

На панели доступны следующие данные и действия:

- **Область статистики:** Можно переключаться между текущим чатом и всем рабочим пространством.
- **Сводка попаданий:** Сравнивайте данные за сегодня, вчера и за все время, включая количество учтенных ходов, процент попаданий и объем чтения из кэша.
- **Распределение токенов:** Отображаются входные токены, чтение и запись кэша, а также выходные токены. Чтение из кэша — это повторно используемые входные токены, которые не требуется обрабатывать заново.
- **Оценка экономии:** Отображаются эквивалент сэкономленных входных токенов и примерная экономия по прейскурантным ценам. Это справочная оценка; фактическая стоимость зависит от провайдера, модели и маршрута.
- **Данные по ходам:** Для каждого хода можно проверить провайдера, модель, параметры рассуждения и скорости, процент попаданий, время и длительность. При выборе хода отображаются итоговые значения входа, чтения и записи кэша, а также выхода.
- **Динамика:** График показывает изменение процента попаданий от старых запросов к новым.
- **Действия:** Можно скопировать сводку или очистить статистику для выбранной области.

![Панель Cache Broadcast](/dialog-box/cache-hit-dashboard.png)

Кэш провайдера является временным. После длительного простоя, перезапуска, смены модели, скорости или серверного маршрута процент попаданий может составить 0%; последующие запросы могут снова прогреть кэш.


## Меню упоминаний

Указатель выделяет область быстрого контекста, используемую для открытия меню упоминаний. Это меню позволяет добавить к текущему сообщению файлы, папки, инструменты MCP и навыки.

![Меню упоминаний в диалоговом окне Breezell](/dialog-box/mention-menu.png)

Используйте его, если запрос зависит от конкретного содержимого рабочего пространства или внешней возможности. Правильный контекст помогает Breezell понять, что нужно проверить или использовать перед ответом.

## Советы по использованию

- Добавляйте контекст файла или папки, если запрос зависит от конкретного содержимого проекта.
- Agent — режим по умолчанию и рекомендуемый автоматический рабочий процесс для большинства задач.
- Переключайте режим только при необходимости определённого рабочего процесса, например планирования перед изменениями или анализа без редактирования.
- Сжатие контекста выполняется автоматически. Используйте ручное сжатие только при необходимости строгого ручного контроля или особом требовании.
- Проверяйте выбранную модель, если важны точность, скорость или глубина рассуждений.
