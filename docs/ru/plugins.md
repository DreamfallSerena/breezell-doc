# Плагины

Плагин Breezell — это расширение VS Code, которое вдобавок получает `vscode.breezell`, поэтому может работать с самим Breezell: чатом, Agent, выбором модели и экранами редактора. Плагины работают только пока вы вошли в Breezell; после выхода они отключаются.

## Установка и управление

Откройте **Box ▸ Плагины**. В маркете перечислены все опубликованные плагины: их можно искать, фильтровать по категориям, переключаться между открытым и закрытым исходным кодом и листать по страницам. На каждой карточке есть «Установить», «Открыть», переключатель включения и «Удалить».

- **Установленные** — по строке на плагин: состояние, версия, источник, лицензия, идентификатор, а также карточки «Окна», «Что добавляет» и «Разрешения».
- **Разработка** создаёт плагин из шаблона и перечисляет шаги от кода до маркета.
- **Установить локальный .vsix** ставит пакет, собранный вами; пакет, контрольная сумма которого не совпадает с опубликованной, не устанавливается.

Плагин, добавляющий панель или окно, появляется также в разделе «Плагины» на боковой панели Box.

## Виды плагинов

| Вид | Что это | Пример |
|---|---|---|
| Pack | Без кода: навыки, правила для ИИ, серверы MCP и темы, объявленные в `package.json` | Starter Pack |
| Panel | Панель внутри Breezell со своей страницей, следующая за разговором | Focus Player |
| AI | Команды, использующие вашу модель чата | Doc Writer |
| Window | Собственное окно, которое может открываться и без редактора | Focus Timer |
| Conversation | Читает разговоры, отправляет сообщения, одобряет вызовы инструментов, а также запускает субагентов, пишет им и закрывает их | Chat Mirror |
| Screens | Кнопки, страницы, заменённые части, блоки кода и режимы на собственных экранах Breezell | Desk Pet |
| Companion | Питомец над полем ввода, повторяющий действия ИИ | Desk Pet |
| Long-running | Ведёт разговор до завершения задачи, с ограничениями и своей страницей | Goal |

Виды сочетаются: один плагин может дать навыки, панель, команды ИИ и окно. Большой пример со страницей настроек, загрузкой данных из релиза GitHub и компонентом, устанавливаемым в систему, — это Breezell IME.

## Создание плагина

В Breezell откройте **Box ▸ Плагины ▸ Разработка**, введите идентификатор и имя, выберите шаблон (Pack, Panel, AI command, Window или Minimal) и открытый либо закрытый исходный код, затем укажите папку и откройте её в новом окне. Нажмите **F5**, чтобы запустить.

Из командной строки (Node.js 18 или новее):

```bash
curl -O https://raw.githubusercontent.com/BreezellCode/BreezellCode/main/plugins/devkit/breezell-plugin.mjs
node breezell-plugin.mjs init my-plugin --id my-name.my-plugin --display-name "My Plugin" --template webview
cd my-plugin
npm install
```

| Команда | Что делает |
|---|---|
| `npm run build` / `npm run watch` | Собирает `src/extension.ts` в `dist/extension.js` через esbuild |
| `npm run typecheck` | Проверка типов TypeScript |
| `npm run validate` | Проверка `package.json` |
| `npm run package:open` | Сборка как открытый код: исходники и source map входят в пакет |
| `npm run package:closed` | Сборка как закрытый код: только минифицированный код, без исходников и source map |
| `npm run submit -- --market` | Добавляет пакет в маркет |

## Что может плагин

Плагин объявляет нужные разрешения в `package.json`; всё, что не объявлено, запрещено. Обычные разрешения, например знать, когда начинается и заканчивается ход, выдаются по умолчанию. Более рискованные — использовать вашу модель чата, читать разговоры, отправлять сообщения, одобрять вызовы инструментов, читать ваш код или поле ввода, менять сообщение до отправки, читать ваши ключи API — запрашиваются при первом использовании, и ответ запоминается.

Плагины не имеют доступа к вашей учётной записи, плану, квоте, оплате, настройкам своих API, диалогам разрешений, одобрению инструментов и экранам управления плагинами. Всё, что требует вашего участия, показывается поверх окна плагина, а добавленная в Breezell кнопка помечается «От плагина: имя».

### Субагенты

В Breezell новее 1.4.56 плагин может работать и с субагентами — отдельными разговорами, которые запускает разговор в режиме «Агент» или «Запутанность»; субагент работает в режиме этого разговора и отчитывается ему. С `chat.read` плагин видит субагентов разговора, какие разговоры являются субагентами и чем занят каждый; с `chat.send` он запускает субагента с задачей, пишет ему и закрывает его. Всё, что плагин отправляет так, показывается как сообщения плагина, а не ваши и не основного агента, а основной агент узнаёт, когда плагин запускает или закрывает его субагента. Подробнее — в разделе [Subagents](https://github.com/BreezellCode/BreezellCode/blob/main/plugins/docs/chat.md#subagents-chatread-chatsend) руководства разработчика.

## Публикация

Сделайте форк [репозитория BreezellCode](https://github.com/BreezellCode/BreezellCode), соберите плагин (`npm run package:open` или `npm run package:closed`), выполните `npm run submit -- --market` и откройте pull request. Запускается проверка маркета, затем его просматривает сопровождающий. Плагины с закрытым кодом содержат только минифицированный код.

Каждый плагин, созданный из шаблона, также содержит навык для ИИ в `.agents/skills/breezell-plugin/` с этими страницами в качестве справочников, поэтому ассистент может работать по тому же руководству.
