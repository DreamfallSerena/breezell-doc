# Введение

Breezell — редактор кода с ИИ, созданный на основе VS Code (Code – OSS). Редактор, ваши расширения и сочетания клавиш работают так, как вы привыкли, а рядом с ними находится ИИ, который может самостоятельно читать ваш проект, редактировать файлы, выполнять команды и пользоваться инструментами.

::: tip Об экранах на этой странице
Экраны Breezell в этом руководстве — не скриншоты: они воссозданы на HTML по исходному коду Breezell. Текст на них следует языку этой страницы, а цвета — переключателю светлой / тёмной темы сайта. Пронумерованные оранжевые метки служат только подписями для этого руководства.
:::

## Окно Breezell

<BzChuangti wen="Загружай файл конфигурации один раз при запуске и кэшируй его." da="Готово. Теперь config.ts читает файл один раз и хранит разобранный результат, а index.ts вызывает loadConfig() до запуска сервера." />

| | Элемент | Что это |
| --- | --- | --- |
| 1 | **Box \| Agent** | Переключает всё окно между страницей **Agent** (ваш код и ИИ) и страницей **Box** (настройки и данные). |
| 2 | Редактор | Редактор Code – OSS с вкладками, проводником, поиском, Git и расширениями. |
| 3 | Чат | Здесь вы общаетесь с ИИ. Чат также можно открыть во вкладке редактора рядом с кодом. |
| 4 | Режим | Какую свободу действий получает ИИ в этом диалоге — от обычного чата до автономных агентов. См. [Режимы](#modes). |
| 5 | Модель | Какая модель отвечает, вместе с параметрами контекста, рассуждения и скорости. |

### Agent и Box

**Agent** — место, где вы работаете: редактор и чат рядом друг с другом.

**Box** — страница управления. На её боковой панели находится группа <BzWenben jian="box.title" /> (модели и провайдеры, параметры функций, общие и языковые настройки, MCP и навыки, конфиденциальность, экспериментальные возможности), а также данные, связанные с вашей работой: <BzWenben jian="box.review.group" />, <BzWenben jian="box.memory.group" />, <BzWenben jian="box.storage.group" />, <BzWenben jian="box.perf.group" />, <BzWenben jian="box.database.group" /> и <BzWenben jian="box.vault.group" />. Пока вы находитесь в Box, чат остаётся открытым.

## Режимы {#modes}

Переключатель режима в левом нижнем углу поля ввода чата определяет, что разрешено делать ИИ. У каждого режима в поле ввода свой цвет:

| Режим | Словами Breezell |
| --- | --- |
| <BzMoshi moshi="normal" /> | <BzWenben jian="chatMode.normalDetail" /> — <BzWenben jian="chatMode.normalExplain" /> |
| <BzMoshi moshi="plan" /> | <BzWenben jian="chatMode.planDetail" /> — <BzWenben jian="chatMode.planExplain" /> |
| <BzMoshi moshi="analyze" /> | <BzWenben jian="chatMode.analyzeDetail" /> — <BzWenben jian="chatMode.analyzeExplain" /> |
| <BzMoshi moshi="entanglement" /> | <BzWenben jian="chatMode.entanglementDetail" /> — <BzWenben jian="chatMode.entanglementExplain" /> |
| <BzMoshi moshi="agent" /> | <BzWenben jian="chatMode.agentDetail" /> — <BzWenben jian="chatMode.agentExplain" /> |
| <BzMoshi moshi="agent_teams" /> | <BzWenben jian="chatMode.agentTeamsDetail" /> |
| <BzMoshi moshi="dark_selene" /> | <BzWenben jian="chatMode.darkSeleneDetail" /> |

Entanglement и Teams открываются после того, как вам помогут пять друзей, или на любом платном плане. Teams и DarkSelene расходуют намного больше токенов, чем остальные режимы. Когда какой режим использовать, объясняет страница [Выбор режима](/mode-selection).

## Модели

Breezell делит модели на четыре вида провайдеров:

- **Breezell**: официальные модели Breezell, расход списывается с вашей квоты Breezell.
- **Вход**: аккаунты, которые у вас уже есть, например ChatGPT (Codex), GitHub Copilot, Kimi, Grok, Gemini, DeepSeek, MiniMax или OpenRouter.
- **API-провайдеры**: официальные API вендоров на вашем собственном ключе, например Anthropic, OpenAI, Gemini или DeepSeek.
- **Совместимые с OpenAI**: до 50 слотов для ретрансляторов, шлюзов и собственных прокси.

Всё, кроме моделей Breezell, работает на вашем собственном ключе или аккаунте. Страница [Пользовательский API (BYOK)](/custom-api) разбирает это на примере моделей Claude.

## Что ещё есть в Breezell

- **Суперпамять**: долговременная память между диалогами с библиотекой памяти, которую можно просматривать и редактировать. См. [Суперпамять](/super-memory).
- **Breezell Mind**: удерживает длинные диалоги в рамках бюджета, сворачивая старую историю в рабочие заметки, при этом исходная запись остаётся на диске.
- **Ревью кода**: страница для проверки изменений ИИ с diff по каждому файлу и откатом в один клик.
- **Breezell Browser**: встроенный браузер, в котором ИИ может открывать страницы, читать их и выполнять на них действия.
- **MCP и навыки**: подключайте внешние инструменты через Model Context Protocol и повторно используйте навыки в разных проектах. См. [Настройки промптов и навыков](/prompt-settings).
- **База данных**: подключайтесь к SQLite, MySQL, PostgreSQL, SQL Server, Oracle, MariaDB, MongoDB и Redis прямо из редактора.
- **Сейф**: хранит адреса ретрансляторов и ключи в системном хранилище учётных данных и подставляет их там, где они нужны.
- **Image Studio**: генерация изображений и видео.
- **Горячие обновления**: новые версии скачиваются прямо в редакторе и вступают в силу после перезапуска, без переустановки.

## Начало работы

1. Скачайте Breezell для вашей платформы и установите его.
2. Войдите в аккаунт Breezell.
3. Выберите язык интерфейса. См. [Настройки языка](/settings-page-language-settings).
4. Выберите модели: сразу начните с моделей Breezell или подключите собственный ключ через [Пользовательский API (BYOK)](/custom-api).
5. Откройте папку проекта, выберите режим и модель под полем ввода чата, опишите, что вам нужно, и отправьте запрос.
