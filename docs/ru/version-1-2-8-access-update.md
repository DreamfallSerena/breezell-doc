# Обновление доступа в версии 1.2.8

Чтобы обеспечить долгосрочную и стабильную работу Breezell, начиная с версии 1.2.8 для Entanglement и Teams будет использоваться разблокировка по приглашениям.

## Правила разблокировки

- **Entanglement и Teams:** Доступ разблокируется после того, как пять приглашённых новых пользователей завершат регистрацию.
- **Текущие платные пользователи:** Приглашения не требуются. Обратитесь к администратору, чтобы разблокировать доступ.
- **Пользователи плана Custom API:** Приглашения не требуются. Обратитесь к администратору, чтобы разблокировать доступ.

## Доступ без изменений

- **Режим Agent:** Это изменение не влияет на режим Agent; он остаётся доступен в обычном порядке.
- **Пользовательский API:** Он остаётся бесплатным и не станет платным из-за этого изменения.

## Область действия обновления

Это обновление меняет только способ разблокировки Entanglement и Teams. Все остальные функции остаются без изменений.
