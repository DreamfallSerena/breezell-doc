# Обновление доступа в версии 1.2.8

Чтобы поддержать долгосрочную работу Breezell, начиная с версии 1.2.8 Entanglement и Teams разблокируются по приглашениям.

::: tip Об экранах на этой странице
Экран Breezell ниже воссоздан на HTML по исходному коду Breezell. Текст на нём следует языку этой страницы.
:::

## Что изменилось {#changes}

- **Entanglement и Teams** разблокируются после того, как пять пользователей Breezell помогут вам по вашей ссылке-приглашению. Разблокировка действует навсегда. См. [Как пригласить новых пользователей](/invite-new-users).
- **Платные тарифы** включают оба режима; приглашения не нужны.
- **Пользователям тарифа Custom API** приглашения тоже не нужны. Если режимы у вас всё ещё заблокированы, обратитесь к администратору.

Пока режимы не разблокированы, в меню режимов у них отображается замок, а при наведении на них виден ваш прогресс:

<BzLiaotian tanchu="moshi" moshi="agent" suoding />

При выборе заблокированного режима появляется сообщение <BzWenben jian="chatMode.entanglementSendBlocked" />

## Что не изменилось {#unchanged}

- **Режим Agent** и все остальные режимы доступны, как и раньше.
- **Пользовательский API (BYOK)** остаётся бесплатным и не становится платным из-за этого изменения. См. [Пользовательский API (BYOK)](/custom-api).
- Все остальные функции остаются без изменений.
