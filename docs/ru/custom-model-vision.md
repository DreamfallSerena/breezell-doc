# Зрение для пользовательских моделей

> Добавьте распознавание изображений пользовательской текстовой модели с помощью отдельной модели с поддержкой зрения.

## Перед началом

Если ваша пользовательская модель не поддерживает мультимодальный ввод, Breezell 1.2.8 позволяет ей получать возможности распознавания изображений через другую модель. Сначала настройте модель с поддержкой зрения, а затем назначьте её пользовательской модели, которой требуется понимание изображений.

## Откройте настройки моделей

1. На панели инструментов в правом верхнем углу редактора нажмите значок-шестерёнку настроек.
2. В меню выберите **Breezell Settings**.
3. На боковой панели настроек выберите **Models**.

Если пользовательская модель ещё не настроена, сначала завершите [настройку пользовательского API](/ru/custom-api).

## Откройте настройки Vision Proxy

1. Найдите в списке моделей пользовательскую модель, которой требуется распознавание изображений.
2. Нажмите маленький значок глаза на этой модели, чтобы открыть **Vision Proxy**.

![Список моделей с выделенной кнопкой Vision Proxy](/custom-model-vision/open-vision-proxy-settings.png)

## Выберите модель распознавания изображений

1. В диалоговом окне **Vision Proxy** откройте селектор **Image recognition model**.
2. Выберите настроенную модель с поддержкой распознавания изображений.
3. Нажмите **Save**, чтобы сохранить выбор.

![Диалог Vision Proxy с выделенными выбором модели распознавания изображений и Save](/custom-model-vision/select-vision-recognition-model.png)

## Начните разговор

Выберите пользовательскую модель в разговоре, прикрепите изображение и отправьте сообщение. Breezell использует выбранную модель распознавания изображений, чтобы помочь пользовательской модели обработать изображение.

![Разговор, в котором пользовательская модель распознаёт прикреплённое изображение через выбранную модель распознавания изображений](/custom-model-vision/custom-model-vision-conversation.png)
