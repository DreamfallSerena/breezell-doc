# Настройки промптов и навыков

Breezell хранит четыре вида постоянных инструкций для ИИ в одной панели — **Rules, Memories & Skills**:

| | Что это | Когда используется |
| --- | --- | --- |
| **Rules** | Инструкции, которым ИИ обязан следовать, например соглашения о коде или язык ответов | В каждом запросе |
| **Memories** | Датированные заметки: факты и решения, которые нужно сохранять между диалогами | Как фоновые заметки; приоритет у вашего последнего запроса |
| **Skills** | Пошаговые сценарии для конкретной задачи, например для написания примечаний к выпуску | ИИ загружает их, когда задача подходит |
| **Commit** | Как должны выглядеть сообщения коммитов Git, созданные ИИ | Когда вы генерируете сообщение коммита |

::: tip Об экранах на этой странице
Экраны Breezell ниже воссозданы на HTML по исходному коду Breezell. Текст на них следует языку этой страницы. Навигация в панели интерактивна. Подписи вроде Rules, Memories, Skills и Commit в Breezell тоже на английском.
:::

## Открытие панели

Нажмите кнопку **Skills & Memory** (значок блокнота) в верхней части панели чата, между **New Chat** (+) и **Chat History**.

<BzLiaotian biaotilan gaoliang="jiyi" biaoji="1" />

Панель также можно открыть через Box ▸ <BzWenben jian="box.title" /> ▸ <BzWenben jian="tab.mcp" />: первая карточка на этой странице — <BzWenben jian="box.mcp.openSkillsMemory" />.

## Рабочая область и глобальный уровень

В левой части панели есть две группы:

- <BzWenben jian="common.workspace" />: только для открытого проекта. Файлы хранятся в папке `.breezell` проекта, поэтому их можно закоммитить и поделиться ими с командой. Если папка не открыта, эта группа неактивна и отображается серым.
- <BzWenben jian="common.global" />: для всех проектов на этом компьютере. Файлы хранятся в папке `.breezell` в вашей домашней папке.

Слева выберите область действия и тип настроек. Заголовок показывает, что именно вы редактируете, а путь внизу — файл, в котором это хранится.

<BzGuize />

Панель сохраняет изменения, когда вы переключаете страницы, уходите из редактора или закрываете панель. Кнопка <BzWenben jian="rulesMemories.clear" /> в правом верхнем углу очищает текущую страницу; нажмите её дважды, чтобы подтвердить.

## Правила

Правила — это обычный Markdown. Пишите короткие конкретные инструкции, которые не противоречат друг другу, например:

```markdown
# Project rules
- Use TypeScript strict mode. Do not add any.
- Run `pnpm test` after changing files under src/.
- Answer in Traditional Chinese; keep code and identifiers in English.
```

| Область | Файл |
| --- | --- |
| <BzWenben jian="common.workspace" /> | `{workspace}/.breezell/rules/breezell.md` |
| <BzWenben jian="common.global" /> | `~/.breezell/memories/global_rules.md` |

::: warning Правила рабочей области заменяют глобальные правила
Если в открытом проекте есть правила рабочей области, Breezell отправляет их, а глобальные правила не включает. Глобальные правила используются только в проектах без правил рабочей области. Если проекту нужны и некоторые из ваших глобальных правил, скопируйте их в его правила рабочей области.
:::

В рабочей области с несколькими папками используются правила каждой папки. Breezell читает сохранённый файл, поэтому несохранённый черновик никогда не попадает к ИИ.

## Память

Записи памяти — это короткие датированные заметки: решения, предпочтения, устройство проекта. ИИ также может сам добавлять сюда заметки с помощью своего инструмента `update_memory`.

Breezell считает записи памяти заметками, а не правилами. Если запись расходится с вашим последним запросом или с текущим кодом, ИИ следует запросу и коду и предлагает обновить запись. Всё, что должно соблюдаться всегда, помещайте в Rules.

<BzGuize fenye="memories" gaoliang="tianjiajiyi" biaoji="1" />

1. Откройте <BzWenben jian="common.workspace" /> ▸ Memories (или <BzWenben jian="common.global" /> ▸ Memories).
2. Нажмите <BzWenben jian="rulesMemories.addMemory" />.
3. Запишите один факт на одну запись и нажмите `Ctrl+Enter` (или кнопку Save).

Каждая запись памяти — это карточка с датой. Чтобы удалить запись, наведите указатель на карточку. Число рядом с Memories в списке слева показывает, сколько всего записей.

| Область | Файл |
| --- | --- |
| <BzWenben jian="common.workspace" /> | `{workspace}/.breezell/memories/workspace_memories.md` |
| <BzWenben jian="common.global" /> | `~/.breezell/memories/global_memories.md` |

Для записей памяти нужен тариф с Super Memory. Без него на странице появляется сообщение <BzWenben jian="superMemory.proRequired" />. О записях памяти, которые ИИ собирает самостоятельно, см. [Super Memory](/super-memory).

## Навыки

Навык — это папка с файлом `SKILL.md`. Breezell передаёт ИИ имя и описание каждого включённого навыка; когда задача соответствует описанию, ИИ загружает полные инструкции этого навыка и следует им. Поэтому в хорошем описании сказано, **когда** использовать навык.

### Создание навыка

1. Откройте <BzWenben jian="common.workspace" /> ▸ Skills (или <BzWenben jian="common.global" /> ▸ Skills) и нажмите <BzWenben jian="skills.newSkill" />.
2. Введите имя: строчные буквы и дефисы, например `release-notes`.
3. Введите описание в одну строку: для чего нужен навык.
4. Напишите инструкции: шаги, правила и ожидаемый результат.
5. Нажмите <BzWenben jian="skills.createSkill" />.

<BzGuize fenye="xinjineng" />

| Область | Папка |
| --- | --- |
| <BzWenben jian="common.workspace" /> | `{workspace}/.breezell/skills/<name>/SKILL.md` |
| <BzWenben jian="common.global" /> | `~/.breezell/skills/<name>/SKILL.md` |

Рядом с `SKILL.md` навык может содержать и другие файлы (справочные материалы, скрипты). Они перечислены на странице навыка, а по щелчку файл открывается.

### Импорт навыков

Перетащите файлы на список навыков: <BzWenben jian="skills.dropZipPrompt" />. Один `.zip` может содержать сразу много папок навыков; отдельный файл `.md` становится одним навыком с именем по названию файла.

### Использование навыков в чате

Нажмите кнопку **Skills** (значок слоёв) в строке под полем ввода чата:

<BzLiaotian jinengpan gaoliang="jineng" biaoji="1" />

- <BzWenben jian="skills.builtinTab" />: навыки, которые поставляются вместе с Breezell, например `brainstorming` или `requesting-code-review`. Они подчиняются переключателю **Superpowers Skills** в <BzWenben jian="box.title" /> ▸ <BzWenben jian="tab.featureOptions" />.
- <BzWenben jian="skills.myTab" />: ваши навыки рабочей области и глобальные навыки.
- Переключатель включает или выключает навык. Выключенный навык не предлагается ИИ.
- Кнопка со стрелкой (<BzWenben jian="inputToolbar.referenceSkill" />) добавляет навык в ваше сообщение, чтобы ИИ использовал его в этом запросе.

Чтобы открыть меню навыков, можно также ввести `/` в поле ввода.

Включение или выключение навыков и MCP-серверов меняет начало промпта, из-за чего вы можете лишиться кэша промптов у провайдера. Настройте всё нужное до начала длинного диалога, а не посреди него.

## Сообщение коммита

Раздел Commit определяет, как Breezell пишет сообщения коммитов Git, когда вы их генерируете.

<BzGuize fenye="commit" />

- Если страница пуста, используется встроенный промпт Breezell в стиле Conventional Commits.
- Текст на странице **заменяет** встроенный промпт полностью. Breezell по-прежнему передаёт модели diff, ветку и последние коммиты, поэтому описывайте только стиль: язык, формат, длину.
- Промпт из раздела <BzWenben jian="common.workspace" /> имеет приоритет над промптом из раздела <BzWenben jian="common.global" />.
- Кнопка <BzWenben jian="rulesMemories.clear" /> восстанавливает встроенный промпт.

| Область | Файл |
| --- | --- |
| <BzWenben jian="common.workspace" /> | `{workspace}/.breezell/rules/commit_prompt.md` |
| <BzWenben jian="common.global" /> | `~/.breezell/memories/global_commit_prompt.md` |

## Итоги

- Rules: то, что ИИ должен делать всегда. Правила рабочей области заменяют глобальные правила.
- Memories: факты, которые нужно запомнить, по одному на карточку.
- Skills: сценарии, которые ИИ загружает, когда задача соответствует их описанию; включайте и выключайте их под полем ввода чата.
- Commit: ваш стиль сообщений коммитов, который заменяет встроенный промпт.
