# Настройки промптов и навыков

На этой странице собраны инструкции, повторно используемые знания и рабочие процессы, доступные Breezell.

## Открытие настроек

Стрелка выделяет кнопку **Rules, Memories & Skills** на панели инструментов в правом верхнем углу. Она находится сразу справа от кнопки **New Chat** (+).

![Кнопка настроек промптов и навыков](/prompt-settings/prompt-and-skill-settings-button.png)

Нажмите кнопку, чтобы открыть панель настроек.

## Уровни Workspace и Global

На боковой панели настройки разделены на два уровня:

- **Workspace:** Применяется только к текущему проекту. Файлы хранятся в каталоге **.breezell** проекта, поэтому настройки остаются связанными с рабочей областью.
- **Global:** Применяется ко всем рабочим областям. Используйте этот уровень для предпочтений и процессов, которые должны быть доступны в любом проекте.

Сначала выберите уровень, затем **Rules**, **Memories**, **Skills** или **Commit**. Метка рядом с заголовком страницы показывает активный уровень.

## Правила

Правила — это пользовательские инструкции, которым Breezell следует на выбранном уровне. В них можно указать стандарты кода, обязательные инструменты, формат ответов, ограничения проекта и другие постоянные требования.

![Настройки правил рабочей области](/prompt-settings/rules-settings.png)

На уровне Workspace файл правил хранится по пути **{workspace}/.breezell/rules/breezell.md**. Формулируйте конкретные и непротиворечивые инструкции. Действие **Clear** удаляет содержимое активного раздела Rules.

## Память

В памяти сохраняются факты, предпочтения, решения и контекст проекта, которые понадобятся в следующих диалогах. Число рядом с **Memories** показывает количество записей на выбранном уровне.

![Редактор памяти рабочей области](/prompt-settings/memory-settings.png)

Добавляйте по одной четко сформулированной записи, затем нажмите **Save** или **Ctrl+Enter**. Память Workspace хранится по пути **{workspace}/.breezell/memories/workspace_memories.md**. На уровне Global сохраняйте только сведения, которые должны действовать в разных проектах.

## Навыки

Навыки — это повторно используемые пакеты инструкций, которые обучают Breezell выполнению конкретной задачи или рабочего процесса. Откройте **Skills** на нужном уровне, чтобы создавать навыки и управлять ими.

![Создание навыка рабочей области](/prompt-settings/skill-creation.png)

Чтобы создать навык:

1. Введите уникальное имя, используя только строчные буквы и дефисы.
2. Добавьте краткое описание, ясно указывающее, когда и для чего используется навык.
3. В основном редакторе запишите инструкции, этапы, ограничения и ожидаемый результат.
4. Нажмите **Create Skill**.

Навык Workspace хранится по пути `{workspace}/.breezell/skills/<name>/SKILL.md`. Ограничьте каждый навык одной повторяемой задачей, чтобы Breezell мог надежно выбрать и применить его.

## Commit

Раздел **Commit** позволяет раздельно управлять настройками, связанными с коммитами, на уровнях Workspace и Global. Требования конкретного проекта размещайте в Workspace, а повторно используемые предпочтения — в Global.
