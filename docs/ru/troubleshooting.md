# Устранение неполадок

На этой странице собраны решения распространённых проблем с установкой и запуском. Новые случаи будут добавляться по мере их появления.

::: tip Об экранах на этой странице
Страница загрузки ниже воссоздана на HTML по исходному коду breezell.com и, как и сам сайт, показана на английском. Диалоговое окно macOS и окно Терминала (Terminal) нарисованы так, чтобы показать, что вы увидите на Mac.
:::

## Выбор подходящей сборки {#download}

Откройте страницу загрузки [breezell.com/download](https://breezell.com/download). Вверху она рекомендует сборку для вашего компьютера, а ниже можно выбрать платформу, чтобы увидеть все сборки. Нажимайте на вкладки здесь, чтобы сравнить их:

<BzXiazai gaoliang="fenye" biaoji="1" />

| Платформа | Сборка | Для чего |
| --- | --- | --- |
| macOS | Apple Silicon | Mac с чипом M1, M2, M3, M4 или новее |
| macOS | Intel | Более старые Mac на процессорах Intel |
| macOS | Universal | Оба типа Mac (устаревшая сборка) |
| Windows | x64 · System / ARM64 · System | Устанавливается для всех пользователей компьютера; нужны права администратора |
| Windows | x64 · User / ARM64 · User | Устанавливается только для вашей учётной записи; права администратора не нужны |
| Linux | .deb | Ubuntu, Debian и производные дистрибутивы (x64, ARM64, ARM32) |
| Linux | .rpm | Fedora, RHEL, CentOS и производные дистрибутивы (x64, ARM64, ARM32) |

Чтобы узнать, какой чип стоит в вашем Mac, откройте меню Apple ▸ **Об этом Mac** (About This Mac). Более ранние выпуски перечислены в разделе **View past versions** внизу страницы загрузки.

## Установка Breezell на macOS {#install-macos}

1. Скачайте со страницы загрузки сборку для своего Mac.
2. Откройте скачанный образ и перетащите **Breezell.app** в папку **Программы** (Applications). Дождитесь окончания копирования.
3. Запустите Breezell из **Finder ▸ Программы**.

## «Breezell.app повреждено» или «неустановленный разработчик» {#damaged}

macOS помечает приложения, загруженные не из App Store, атрибутом карантина. На некоторых Mac из-за этого macOS отказывается открывать Breezell и показывает предупреждение вроде этого, хотя приложение не повреждено:

<BzXiazai ye="jinggao" />

Нажмите **Отменить** (Cancel), а не **Переместить в Корзину** (Move to Trash), и один раз выполните шаги ниже. Те же шаги показаны на странице загрузки, если выбрана macOS:

<BzXiazai gaoliang="zhinan" biaoji="1" />

### 1. Откройте Терминал {#open-terminal}

Нажмите **Command (⌘) + Пробел**, чтобы открыть Spotlight, введите **Терминал** и нажмите **Return**. Терминал также можно найти в **Программы ▸ Утилиты (Utilities) ▸ Терминал**.

### 2. Снимите с Breezell атрибут карантина {#remove-quarantine}

Вставьте эту команду и нажмите **Return**:

```bash
sudo xattr -rd com.apple.quarantine "/Applications/Breezell.app"
```

Терминал запросит пароль администратора Mac. Введите его и нажмите **Return**; символы при вводе не отображаются.

<BzXiazai ye="zhongduan" />

Если команда ничего не вывела, обычно это значит, что она сработала. Она снимает атрибут карантина только с **Breezell.app**; Gatekeeper и проверки безопасности для других приложений остаются без изменений.

### 3. Снова откройте Breezell {#reopen}

Вернитесь в папку **Программы** и запустите Breezell.

::: warning Безопасность
Делайте это только для Breezell, скачанного с официального сайта. Не снимайте атрибут карантина с приложений, источнику которых вы не доверяете.
:::

## «No such file or directory» {#no-such-file}

Команда не нашла приложение по пути `/Applications/Breezell.app`. Переместите Breezell в папку **Программы** и проверьте, что оно называется именно **Breezell.app**. Если приложение хранится в другом месте, замените в команде `/Applications/Breezell.app` на его фактический путь.
