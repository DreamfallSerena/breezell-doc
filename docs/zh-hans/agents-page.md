# Agents 页面

Agents 页面是 Breezell 的一个页面，把**所有项目的对话放在同一处**：左边是侧栏，列出每个项目和它的对话；右边是和 IDE 一样的编辑区，可以并排打开文件、对话和内置浏览器。你不必先打开某个项目的窗口，就能看到每个 AI 在做什么、哪一个在等你回复，也能直接在这里接着做。

本页说明的是 Breezell 1.4.58（Agents 页面在这个版本推出）。内容包括：怎么切换页面、侧栏的每个部分、怎么添加项目、对话的右键菜单、怎么处理其他项目的对话、右侧面板、账号栏、多项目工作区，以及目前的限制。

## 怎么到这一页 {#open}

标题栏有一组切换：**Agents | IDE | Box**。点 **Agents** 就到这一页，点 **IDE** 回到原来的编辑器，点 **Box** 打开模型、功能选项和全部设置的页面。

- 新打开的窗口默认停在 Agents 页面。
- 关掉窗口后再打开，窗口会回到关闭时所在的页面（Agents、IDE 或 Box）。
- 为了显示文件而打开的窗口（例如用 Breezell 打开某个文件）一律停在 IDE。
- 不想让新窗口先停在 Agents 页面，可以关掉：点页面右上角的**更多**（⋯），取消勾选**打开窗口时显示此页**；也可以在**设置**里搜索“Agents page”，取消勾选“Open new windows on the Agents page”（这个设置的文字是英文）。

| 名词 | 意思 |
| --- | --- |
| 项目 | 一个文件夹（或一个多文件夹工作区），可以在本机、WSL 或 SSH 上。 |
| Agent | 一则对话。在侧栏里每则对话都是一个 Agent。 |
| 子代理 | 由某个对话启动的对话，列在启动它的对话下面。 |
| 右侧面板 | 页面右边的编辑区：文件、对话标签页和内置浏览器并排。 |

## 侧栏 {#sidebar}

侧栏最上面是四个入口：

- **新对话**：在这个窗口的项目开始一则新对话。
- **Box**：切到 Box 页面。
- **自定义**：规则、记忆与技能。
- 搜索按钮（**搜索对话**）：打开搜索框，输入关键字筛选对话；按 `Esc` 清除并关闭。

再下面是 **Agent** 区，按项目列出对话：

- 第一个是这个窗口的项目。后面是其他有对话的项目，以及你自己添加进来的项目，按最近使用的顺序排列。
- 每个项目行显示它的环境（例如 `WSL: ubuntu`、`SSH: host`）、上次使用的时间，以及一个 **+**。点 **+**（提示文字“在「项目名称」新建 Agent”）就会在那个项目开始新的对话。
- 对话前面有一个圆点，表示状态：**正在工作**、**等你回复**，或空闲（没有特别标示）。圆点后面是这则对话距现在多久，例如“刚刚”“5分”“2小时”。
- 项目下面对话太多时，点**显示更多**展开。

要把侧栏收起来，点侧栏左上角的按钮（**切换侧边栏**）；收起后，页面顶端会有按钮让你再打开它，旁边还有一个**新对话**按钮。

## 排列方式 {#group-by}

**Agent** 标题旁的筛选按钮（**排列方式**）可以选三种：

- **按项目**：每个项目一组，这是默认。
- **按时间**：所有对话混在一起，由新到旧排列，每一行会注明它属于哪个项目。
- **按状态**：分成**进行中**、**等你回复**和**其他**三组，一眼就看得出哪个 Agent 在等你。

## 添加项目 {#add}

侧栏只会列出有对话的项目。想让某个文件夹一开始就出现在侧栏，点 **Agent** 标题旁的文件夹按钮（**添加项目…**）：

- 如果只有一个地方可选，会直接打开文件夹选择器，可以一次选好几个文件夹。
- 如果有好几个地方可选，会先弹出菜单：在本机窗口里是**添加 Windows 文件夹…**；有 WSL 时，还有**添加 WSL 文件夹…**；在 WSL 或 SSH 窗口里则是**添加“环境名称”的文件夹…**。你以前用过的环境（例如某台 SSH 主机）会列成**添加“环境名称”的项目…**，可以勾选它上面的项目，也可以直接输入完整路径。菜单最下面是**连接到其他主机…**。

添加进来的项目会一直留在侧栏，直到你移除它。

在项目行上点右键，会出现：

- **在「项目名称」新建 Agent**：和 **+** 一样。
- **在 IDE 中打开**：到 IDE 页面；其他项目的话，会显示它自己的窗口（没打开就先打开）。
- **从侧栏移除**：把这个项目从侧栏拿掉（不会删除任何文件或对话）。这个窗口自己的项目不能移除。

## 对话的右键菜单 {#menu}

在侧栏的对话上点右键，菜单内容视这则对话属于哪个项目而不同。

**这个窗口的项目的对话：**

- **在右侧打开**：把这则对话打开成右侧面板的一个标签页。
- **引用对话**：把这则对话放进当前输入框，AI 需要时才会去读它。
- **重命名**、**置顶**（已置顶时是**取消置顶**）、**收藏**（已收藏时是**取消收藏**）。
- **导出聊天记录**：只有这个窗口的对话才有这一项。
- **删除**。

**其他项目的对话：**

- **在右侧打开**、**引用对话**。
- **在它的窗口继续**：到那个项目自己的窗口接着做。
- **重命名**、**置顶**、**收藏**、**删除**：都会在那个项目里完成。
- 没有**导出聊天记录**。

## 子代理 {#subagents}

子代理是由某个对话启动的对话。它们列在启动它们的对话下面，按启动的顺序排列，缩进一层。

- 有子代理的对话行上有一个按钮，点一下可以**收起子代理**；收起来之后，旁边会显示子代理的数量，再点（**展开子代理**）就会展开。收起或展开的状态会被记住。
- 点一个子代理，会在右侧面板打开成一个标签页。

## 其他项目的对话 {#other}

在侧栏点其他项目的对话，主区域会把它读出来。你可以先看它做了什么；如果要接着做，直接在这里的输入框里写字就行，这则对话会在那个项目里继续，页面上会实时显示它的进度。

在这里做的下列事情，都是在那个项目里进行的：

- 发送消息、修改以前的消息。
- 批准或拒绝 AI 要执行的动作，以及点**停止**。
- 对修改栏点**保留全部**或**撤销全部**。

如果那个项目当前没有打开窗口，Breezell 会在后台打开一个，你看不到它。它空闲一阵子之后会自己关掉：没有东西在运行、没有人在看它、也没有未保存的文件。如果你想看它的窗口，在项目行上点右键，选**在 IDE 中打开**。

AI 回复里的文件链接，会在那个项目里打开，并跳到正确的那一行。

如果想改在那个项目自己的窗口接着做，在侧栏的对话上点右键，选**在它的窗口继续**。

## 右侧面板 {#right}

右侧面板就是编辑区，和在 IDE 里一样：文件、对话标签页和内置浏览器可以并排打开。

- 把侧栏的对话拖到右侧面板，就能并排查看；也可以用右键菜单的**在右侧打开**。
- 页面上方的按钮（**显示右侧面板** / **隐藏右侧面板**）可以收起或打开它。
- 拖动侧栏的边缘可以调整宽度，在边缘上双击恢复默认宽度。右侧面板的边缘也可以拖动来调整大小。

## 账号栏 {#account}

侧栏最下面是账号栏：

- 头像、名称、套餐和余额（团队成员不显示余额）。点它会打开账号面板。
- 齿轮（**设置**）打开 Breezell 的设置。
- **更多**（⋯）的菜单有：**管理套餐**、**版本更新**、**反馈意见**和**退出登录**。
- 还没登录时，这里显示**登录**和“登录你的 Breezell 账号”；点它就会开始登录。

## 多项目工作区 {#workspaces}

如果你把好几个项目合并成了一个窗口（见[项目分组与共享记忆](/zh-hans/project-group)），这个窗口的项目行显示的是“多项目工作区”，名称旁列出它里面有哪些项目。

从成员项目带进来的对话，标题不再写成“[项目名称]”，而是在标题前面显示一个小小的彩色标签，标示它来自哪个项目。

## 自动批准的提示 {#auto-approve}

开着自动批准时，有些动作仍然会停下来问你，卡片上也会说明原因，例如：“已开启自动批准，但这个命令可能删除整个文件夹，或删除范围无法事先确定，所以需要你确认。”会这样的情况有：

- 可能删除整个文件夹的命令，或删除范围无法事先确定的命令。
- 修改 AI 的规则、技能、记忆或 MCP 设置。
- 修改会自动运行的文件（git 配置与 hook、工作区设置与任务、shell 配置文件）。
- 修改 SSH 密钥或 SSH 配置。
- 删除工作区、主目录，或工作区外的整个文件夹。

在 Agents 页面里处理其他项目的对话时，这些确认也一样会出现。

## 目前的限制 {#limits}

- 在其他项目的对话里，只会发送文字；附加的文件和图片不会发送。
- 在其他项目的对话里，出错的回复上没有**重试**按钮可用。
- 在本机窗口里，打不开 SSH 项目的文件链接。
- 选**按状态**排列时，其他项目的 Agent 一律列在**其他**里，不分进行中或等你回复。
