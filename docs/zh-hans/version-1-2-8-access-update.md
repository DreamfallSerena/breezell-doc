# 1.2.8 版本调整说明

为了维持 Breezell 的长期稳定运营，Entanglement 和 Teams 将从 1.2.8 版本开始调整为邀请解锁制。

## 解锁规则

- **Entanglement 和 Teams：** 邀请 5 名新用户完成注册后即可解锁。
- **此前的付费用户：** 无需邀请，可直接联系管理员解锁。
- **Custom API 套餐用户：** 无需邀请，可直接联系管理员解锁。

## 不受影响的功能

- **Agent 模式：** 不受此次调整影响，可继续正常使用。
- **自定义 API：** 依然免费，不会因为此次调整收费。

## 调整范围

此次调整仅涉及 Entanglement 和 Teams 的解锁方式，其余功能保持不变。

## 感谢支持

感谢大家的理解与支持。我们会继续维护和完善 Breezell，希望在尽量不影响现有用户体验的情况下，让项目能够长期稳定运营。
