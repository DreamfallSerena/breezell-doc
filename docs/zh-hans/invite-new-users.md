# 邀请新用户教程

所有付费套餐都包含 Entanglement 和 Teams。使用 Free 套餐时，只要有 5 名 Breezell 用户通过你的专属邀请链接为你助力，就能**永久**解锁这两种模式。

::: tip 关于本页的界面示意
下面的界面都是依照 breezell.com 和 Breezell 的源码用 HTML 重新搭建的。官网只提供中文和英文两种语言，因此和真实网站一样，官网界面在本指南的中文页面上显示中文，在其他语言的页面上显示英文。
:::

## 开始之前 {#before}

- 你需要一个 Breezell 账号。请在 [breezell.com](https://breezell.com) 上登录你在编辑器中使用的同一个账号。
- 为你助力的好友需要有自己的 Breezell 账号。他们可以在接受邀请时注册。

## 1. 打开账户设置 {#open}

在 [breezell.com](https://breezell.com) 上登录，点击右上角的头像，然后点击 **Profile**。

<BzWangzhan ye="caidan" gaoliang="profile" biaoji="1" />

进入账户页面后，点击左侧边栏中的 **Settings**。你也可以通过侧边栏底部的账户菜单（**Account settings**）直接前往。

## 2. 生成邀请链接 {#generate}

Settings 中有一张显示你进度的解锁卡片。点击按钮即可生成链接：

<BzWangzhan ye="shezhi" :jindu="2" gaoliang="shengcheng" biaoji="2" />

链接生成后会显示在卡片上，按钮也会变为重新生成链接和复制链接。可以在这里试一试：

<BzWangzhan ye="shezhi" :jindu="2" lianjie gaoliang="fuzhi" biaoji="3" />

复制后，剪贴板中会放入一段简短的消息和你的链接：

```text
「可以帮我助力吗？我在 Breezell 编辑器等你」
https://breezell.com/mode-invite/entanglement?token=YOUR_INVITE_TOKEN
```

上面的 token 只是占位符：请发送你自己的账号生成的文字。

## 3. 好友为你助力 {#assist}

好友打开链接。如果尚未登录，需要先登录或注册：

<BzWangzhan ye="yaoqing" zhuangtai="weidenglu" />

然后点击一下即可确认：

<BzWangzhan ye="yaoqing" gaoliang="zhuli" biaoji="1" />

页面会确认助力成功，并显示你最新的进度，例如 3/5。

<BzWangzhan ye="yaoqing" zhuangtai="chenggong" />

### 助力规则 {#rules}

- 集齐 5 次助力，即可为你的账号永久解锁 Entanglement 和 Teams。
- 每个账号只能为一位用户助力。已经为别人助力过的好友会看到这条提示：

<BzWangzhan ye="yaoqing" zhuangtai="yizhuli" />

- 每台设备只能用于一次助力。
- 你不能为自己助力。
- 任意付费套餐都包含这两种模式，无需助力。

## 4. 查看进度 {#progress}

你的进度会显示在 Settings 的解锁卡片上，也可以在编辑器中查看：打开输入框下方的模式菜单，将鼠标悬停在 Entanglement 或 Teams 上。

<BzLiaotian tanchu="moshi" moshi="agent" suoding />

收到第 5 次助力后，锁就会消失，两种模式都可以选择。如果网站无法读取你的解锁状态，卡片上会给出提示并提供重试按钮；退出后重新登录也能解决问题。

## 为什么采用邀请制 {#why}

Breezell 的基础设施、维护和开发都需要持续的资金投入。通过邀请好友，你无需购买套餐也能解锁高级模式，同时还能帮助 Breezell 发展壮大。感谢你的支持。1.2.8 版本的具体变化参见[1.2.8 版本调整说明](/version-1-2-8-access-update)。
