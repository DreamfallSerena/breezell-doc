# 邀请新用户教程

Breezell 会为您的账号生成专属邀请链接，您可以将它分享给新用户。符合条件的受邀用户完成注册并接受邀请后，相关进度会计入 Entanglement 和 Teams 的解锁进度。

## 开始前

请确认您已有 Breezell 账号，并且已登录官方网站。

## 打开官网和个人菜单

1. 打开 Breezell 官方网站：[https://breezell.com](https://breezell.com)。
2. 如果尚未登录，请先登录您的 Breezell 账号。
3. 点击页面右上角的个人头像。

![Breezell 官网中突出显示的个人头像](/invitation-guide/open-profile-menu.png)

## 进入 Profile 页面

1. 在账号菜单中找到 **Profile**。
2. 点击 **Profile** 进入个人资料页面。

![账号菜单中突出显示的 Profile 入口](/invitation-guide/select-profile.png)

## 生成邀请链接

1. 在 Profile 页面左侧选择 **Account**。
2. 找到 **Unlock Entanglement and Teams Modes** 区域。
3. 点击 **Generate invite link**。

![Account 页面中的 Generate invite link 按钮](/invitation-guide/generate-invite-link.png)

::: tip 提示
如果暂时无法读取解锁状态，请先退出账号并重新登录，然后返回 Account 页面再次查看。
:::

## 把邀请发送给朋友

生成链接后，Breezell 会提供类似下面的消息：

```text
Can you help me unlock this? I'm waiting in the Breezell editor.
https://breezell.com/mode-invite/entanglement?token=YOUR_INVITE_TOKEN
```

上面的 Token 仅为占位示例。请复制您自己账号实际生成的完整消息和链接，然后发送给朋友。

您的朋友可以打开链接，完成注册或登录，并接受邀请。符合条件的新用户完成所需注册流程后，会计入您的解锁进度。

## 为什么需要这样做

很抱歉此次调整可能给您带来不愉快的体验。Breezell 需要持续的资助，用于承担基础设施、维护和后续开发成本。

感谢您对项目的支持，也感谢您帮助 Breezell 实现长期稳定运营。
