# Agents 頁面

Agents 頁面是 Breezell 的一個頁面，把**所有專案的對話放在同一處**：左邊是側欄，列出每個專案和它的對話；右邊是和 IDE 一樣的編輯區，可以並排開檔案、對話和內建瀏覽器。你不必先開哪個專案的視窗，就能看到每個 AI 在做什麼、哪一個在等你回覆，也能直接在這裡接著做。

本頁說明的是 Breezell 1.4.58（Agents 頁面在這個版本推出）。內容包括：怎麼切換頁面、側欄的每個部分、怎麼加入專案、對話的右鍵選單、怎麼處理其他專案的對話、右側面板、帳號列、多專案工作區，以及目前的限制。

## 怎麼到這一頁 {#open}

標題列有一組切換：**Agents | IDE | Box**。點 **Agents** 就到這一頁，點 **IDE** 回到原本的編輯器，點 **Box** 打開模型、功能選項和所有設定的頁面。

- 新開的視窗預設停在 Agents 頁面。
- 關掉視窗後再打開，視窗會回到關閉時所在的頁面（Agents、IDE 或 Box）。
- 為了顯示檔案而開的視窗（例如用 Breezell 開啟某個檔案）一律停在 IDE。
- 不想讓新視窗先停在 Agents 頁面，可以關掉：按頁面右上角的 **更多**（⋯），取消勾選**開啟視窗時顯示此頁**；也可以在**設定**裡搜尋「Agents page」，取消勾選「Open new windows on the Agents page」（這個設定的文字是英文）。

| 名詞 | 意思 |
| --- | --- |
| 專案 | 一個資料夾（或一個多資料夾工作區），可以在本機、WSL 或 SSH 上。 |
| Agent | 一則對話。在側欄裡每則對話都是一個 Agent。 |
| 子代理 | 由某個對話啟動的對話，列在啟動它的對話下面。 |
| 右側面板 | 頁面右邊的編輯區：檔案、對話分頁和內建瀏覽器並排。 |

## 側欄 {#sidebar}

側欄最上面是四個入口：

- **新對話**：在這個視窗的專案開始一則新對話。
- **Box**：切到 Box 頁面。
- **自訂**：規則、記憶與技能。
- 搜尋按鈕（**搜尋對話**）：打開搜尋框，輸入關鍵字篩選對話；按 `Esc` 清除並關閉。

再下面是 **Agent** 區，按專案列出對話：

- 第一個是這個視窗的專案。後面是其他有對話的專案，以及你自己加進來的專案，依最近使用的順序排列。
- 每個專案列顯示它的環境（例如 `WSL: ubuntu`、`SSH: host`）、上次使用的時間，以及一個 **+**。按 **+**（提示文字「在「專案名稱」開新 Agent」）就會在那個專案開始新的對話。
- 對話前面有一個圓點，表示狀態：**正在工作**、**等你回覆**，或閒置（沒有特別標示）。圓點後面是這則對話離現在多久，例如「剛剛」「5分」「2小時」。
- 專案下面對話太多時，按**顯示更多**展開。

要把側欄收起來，按側欄左上角的按鈕（**切換側邊欄**）；收起後，頁面頂端會有按鈕讓你再打開它，旁邊還有一顆**新對話**。

## 排列方式 {#group-by}

**Agent** 標題旁的篩選按鈕（**排列方式**）可以選三種：

- **依專案**：每個專案一組，這是預設。
- **依時間**：所有對話混在一起，由新到舊排列，每一列會註明它屬於哪個專案。
- **依狀態**：分成 **進行中**、**等你回覆** 和 **其他** 三組，一眼就看得出哪個 Agent 在等你。

## 加入專案 {#add}

側欄只會列出有對話的專案。想讓某個資料夾一開始就出現在側欄，按 **Agent** 標題旁的資料夾按鈕（**加入專案…**）：

- 如果只有一個地方可選，會直接開資料夾選擇器，可以一次選好幾個資料夾。
- 如果有好幾個地方可選，會先跳出選單：在本機視窗裡是**加入 Windows 資料夾…**；有 WSL 時，還有**加入 WSL 資料夾…**；在 WSL 或 SSH 視窗裡則是**加入「環境名稱」的資料夾…**。你以前用過的環境（例如某台 SSH 主機）會列成**加入「環境名稱」的專案…**，可以勾選它上面的專案，也可以直接輸入完整路徑。選單最下面是**連線到其他主機…**。

加進來的專案會一直留在側欄，直到你移除它。

在專案列上按右鍵，會出現：

- **在「專案名稱」開新 Agent**：和 **+** 一樣。
- **在 IDE 開啟**：到 IDE 頁面；其他專案的話，會顯示它自己的視窗（沒開就先開起來）。
- **從側欄移除**：把這個專案從側欄拿掉（不會刪除任何檔案或對話）。這個視窗自己的專案不能移除。

## 對話的右鍵選單 {#menu}

在側欄的對話上按右鍵，選單內容視這則對話屬於哪個專案而不同。

**這個視窗的專案的對話：**

- **在右側打開**：把這則對話開成右側面板的一個分頁。
- **引用對話**：把這則對話放進目前輸入框，AI 需要時才會去讀它。
- **重新命名**、**置頂**（已置頂時是**取消置頂**）、**收藏**（已收藏時是**取消收藏**）。
- **匯出聊天記錄**：只有這個視窗的對話才有這一項。
- **刪除**。

**其他專案的對話：**

- **在右側打開**、**引用對話**。
- **在它的視窗繼續**：到那個專案自己的視窗接著做。
- **重新命名**、**置頂**、**收藏**、**刪除**：都會在那個專案裡完成。
- 沒有**匯出聊天記錄**。

## 子代理 {#subagents}

子代理是由某個對話啟動的對話。它們列在啟動它們的對話下面，依啟動的順序排列，縮排一層。

- 有子代理的對話旁有一個按鈕，按一下可以**收起子代理**；收起來之後，旁邊會顯示子代理的數量，再按（**展開子代理**）就會展開。收起或展開的狀態會記住。
- 點一個子代理，會在右側面板開成一個分頁。

## 其他專案的對話 {#other}

在側欄點其他專案的對話，主區域會把它讀出來。你可以先看它做了什麼；如果要接著做，直接在這裡的輸入框寫字就行，這則對話會在那個專案裡繼續，頁面上會即時顯示它的進度。

在這裡做的下列事情，都是在那個專案裡進行的：

- 送出訊息、修改以前的訊息。
- 核准或拒絕 AI 要執行的動作，以及按**停止**。
- 對修改列按**保留全部**或**撤銷全部**。

如果那個專案目前沒有開著視窗，Breezell 會在背景開一個，你看不到它。它閒置一陣子之後會自己關掉：沒有東西在執行、沒有人在看它、也沒有尚未儲存的檔案。如果你想看它的視窗，在專案列上按右鍵，選 **在 IDE 開啟**。

AI 回覆裡的檔案連結，會在那個專案裡打開，並跳到正確的那一行。

如果想改在那個專案自己的視窗接著做，在側欄的對話上按右鍵，選**在它的視窗繼續**。

## 右側面板 {#right}

右側面板就是編輯區，和在 IDE 裡一樣：檔案、對話分頁和內建瀏覽器可以並排開。

- 把側欄的對話拖到右側面板，就能並排查看；也可以用右鍵選單的**在右側打開**。
- 頁面上方的按鈕（**顯示右側面板** / **隱藏右側面板**）可以收起或打開它。
- 拖動側欄的邊緣可以調整寬度，在邊緣上按兩下恢復預設寬度。右側面板的邊緣也可以拖動來調整大小。

## 帳號列 {#account}

側欄最下面是帳號列：

- 頭像、名稱、方案和餘額（團隊成員不顯示餘額）。點它會打開帳號面板。
- 齒輪（**設定**）打開 Breezell 的設定。
- **更多**（⋯）的選單有：**管理方案**、**版本更新**、**意見回饋**和**登出**。
- 還沒登入時，這裡顯示**登入**和「登入你的 Breezell 帳號」；按它就會開始登入。

## 多專案工作區 {#workspaces}

如果你把好幾個專案合併成了一個視窗（見[專案分組與共享記憶](/zh-hant/project-group)），這個視窗的專案列顯示的是「多專案工作區」，名稱旁列出它裡面有哪些專案。

從成員專案帶進來的對話，標題不再寫成「[專案名稱]」，而是在標題前面顯示一個小小的彩色標籤，標示它來自哪個專案。

## 自動核准的提示 {#auto-approve}

開著自動核准時，有些動作仍然會停下來問你，卡片上也會說明原因，例如：「已開啟自動核准，但這個命令可能刪除整個資料夾，或刪除範圍無法事先確定，所以要請你確認。」會這樣的情況有：

- 可能刪除整個資料夾的命令，或刪除範圍無法事先確定的命令。
- 修改 AI 的規則、技能、記憶或 MCP 設定。
- 修改會自動執行的檔案（git 設定與 hook、工作區設定與任務、shell 設定檔）。
- 修改 SSH 金鑰或 SSH 設定。
- 刪除工作區、家目錄，或工作區外的整個資料夾。

在 Agents 頁面裡處理其他專案的對話時，這些確認也一樣會出現。

## 目前的限制 {#limits}

- 在其他專案的對話裡，只會送出文字；附加的檔案和圖片不會送出。
- 在其他專案的對話裡，出錯的回覆上沒有**重試**按鈕可用。
- 在本機視窗裡，打不開 SSH 專案的檔案連結。
- 選**依狀態**排列時，其他專案的 Agent 一律列在**其他**裡，不分進行中或等你回覆。
