# 1.2.8 版本調整說明

為了維持 Breezell 的長期穩定營運，Entanglement 和 Teams 將從 1.2.8 版本開始調整為邀請解鎖制。

## 解鎖規則

- **Entanglement 和 Teams：** 邀請 5 名新使用者完成註冊後即可解鎖。
- **先前的付費使用者：** 無需邀請，可直接聯絡管理員解鎖。
- **Custom API 方案使用者：** 無需邀請，可直接聯絡管理員解鎖。

## 不受影響的功能

- **Agent 模式：** 不受此次調整影響，可繼續正常使用。
- **自訂 API：** 依然免費，不會因為此次調整而收費。

## 調整範圍

此次調整僅涉及 Entanglement 和 Teams 的解鎖方式，其餘功能保持不變。

## 感謝支持

感謝大家的理解與支持。我們會繼續維護和完善 Breezell，希望在盡量不影響現有使用者體驗的情況下，讓專案能夠長期穩定營運。
