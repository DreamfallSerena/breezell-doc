# 1.2.8 版本調整說明

為了支持 Breezell 長期營運，自 1.2.8 版本起，Entanglement 和 Teams 改為透過邀請解鎖。

::: tip 關於本頁的畫面
下方的 Breezell 畫面是根據 Breezell 原始碼以 HTML 重新繪製而成，文字會跟著本頁的語言顯示。
:::

## 變更內容 {#changes}

- **Entanglement 和 Teams** 需要五位 Breezell 使用者透過你的邀請連結為你助力後才會解鎖，而且解鎖是永久的。請參閱[邀請新使用者教學](/invite-new-users)。
- **付費方案**包含這兩個模式，不需要邀請。
- **Custom API 方案使用者**同樣不需要邀請。如果這些模式對你仍然是鎖定狀態，請聯絡管理員。

在解鎖之前，這兩個模式會在模式選單中顯示鎖頭圖示，將游標移到上面即可查看你的進度：

<BzLiaotian tanchu="moshi" moshi="agent" suoding />

選擇已鎖定的模式時，會顯示 <BzWenben jian="chatMode.entanglementSendBlocked" />

## 沒有變更的部分 {#unchanged}

- **Agent 模式**和其他所有模式都和以前一樣可以使用。
- **自訂 API（BYOK）** 仍然免費，不會因為這次調整而變成付費功能。請參閱[自訂 API（BYOK）](/custom-api)。
- 其他所有功能都維持不變。

## 感謝支持 {#thanks}

感謝你的理解與支持。我們會持續維護和改進 Breezell，讓它能夠長期穩定運作，同時盡可能減少對現有使用者的影響。
