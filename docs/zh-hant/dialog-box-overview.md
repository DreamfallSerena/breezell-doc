# 對話方塊總覽

Breezell 對話方塊是撰寫提示詞、選擇工作模式、選取模型、附加內容，以及控制 Agent 處理目前請求方式的主要位置。

本頁面介紹對話方塊截圖中顯示的可見控制項。

## 預設輸入狀態

預設輸入狀態是新訊息的正常起始狀態。它會保持提示詞欄位和必要控制項可見。

![預設輸入狀態](/dialog-box/input-default.png)

輸入請求，並在需要時選擇模式和模型，然後將訊息傳送給 Breezell。

## 模式選取器選單

指標突顯模式選取器選單。此選單列出可用的工作模式。

![模式選取器選單](/dialog-box/mode-selector.png)

可用模式包括：

- [**Chat**](/zh-hant/mode-selection#chat)，用於快速提問和回答
- [**Plan**](/zh-hant/mode-selection#plan)，用於編輯前制定實作計畫
- [**Analyze**](/zh-hant/mode-selection#analyze)，用於唯讀調查
- [**Entanglement**](/zh-hant/mode-selection#entanglement)，用於更深入的因果推理
- [**Agent**](/zh-hant/mode-selection#agent)，用於自主編輯檔案和使用工具
- [**Teams**](/zh-hant/mode-selection#teams)，用於複雜工作中的平行 AI 隊友

如需更多詳細資料，請參閱[模式選擇](/zh-hant/mode-selection)。選擇符合你所需自主程度和深度的模式。

## 模型選取器

指標突顯模型選取器。選取器會顯示目前模型，並讓你在傳送訊息前切換到其他可用模型。

![模型選取器](/dialog-box/input-compact-controls.png)

當你想選擇具有不同速度、推理能力或功能特徵的模型時，可以使用此控制項。

## 檔案上傳

指標突顯檔案上傳控制項。

![檔案上傳控制項](/dialog-box/input-model-controls.png)

點選此控制項，在將目前訊息傳送給 Breezell 前附加本機檔案。上傳的檔案會成為請求內容的一部分，因此 Breezell 可以在回答時檢查或參照它們。

## ~~進階探索~~

> **1.2.5 版本後已棄用。** 專用的進階探索控制項已不再提供。當請求需要更深入的研究時，Breezell 會自動呼叫相關功能，進行主動學習、更廣泛的調查和更徹底的探索。

![進階探索控制項](/dialog-box/input-tools-expanded.png)

## Breezell 瀏覽器

指標突顯 **Breezell Browser** 控制項。

![Breezell Browser 控制項](/dialog-box/input-agent-basic.png)

Breezell Browser 是 Breezell 內建的瀏覽器工具。你可以使用它開啟網頁、檢視線上內容、搜尋資訊，並協助 AI 在不離開對話方塊的情況下取得和分析網頁內容。

## 內容用量明細

指標突顯內容用量指示器。開啟後會顯示目前內容視窗使用情況的詳細明細。

![內容用量明細](/dialog-box/context-usage-breakdown.png)

明細會將用量分為系統提示詞、工具、規則、記憶、技能、MCP、子 Agent 和對話內容等類別。你可以利用它了解工作階段中哪些部分消耗了最多權杖。

## 手動壓縮內容

指標突顯內容面板中的 **Manual compress** 控制項。此操作會摘要較早的對話內容，使工作階段在降低內容用量的同時保留有用資訊。

![包含手動壓縮功能的內容面板](/dialog-box/context-manual-compress.png)

手動壓縮適用於長時間對話，尤其是內容視窗變大但你仍想繼續使用同一工作階段時。

## 快速片語

指標突顯輸入托盤中的 **Quick Phrases（快速片語）** 按鈕。快速片語可儲存常用提示詞或指令，之後無需重複輸入即可在新訊息中重複使用。

![輸入托盤中的快速片語按鈕](/dialog-box/quick-phrases-button.png)

開啟 **Quick Phrases** 後，使用 **Add** 建立片語。左側 **All phrases** 顯示所有已儲存的片語；將常用片語拖曳到右側 **Favorites** 即可加入收藏，拖回左側可取消收藏。

選擇已儲存的片語即可將其插入目前的輸入欄。傳送訊息前仍可繼續編輯片語內容。

![快速片語管理介面](/dialog-box/quick-phrases-manager.png)

## MCP 伺服器

指標突顯輸入托盤中的 **MCP** 按鈕。開啟後可檢視已設定的 MCP 伺服器，並控制現有 MCP 伺服器的啟用狀態。

![MCP 伺服器控制面板](/dialog-box/mcp-server-controls.png)

每個伺服器項目提供以下功能：

- **呼叫箭頭：** 點選後會在目前的輸入欄中插入 `/mcp:<伺服器名稱>`。傳送包含此參照的請求，即可讓 AI 呼叫所選 MCP 伺服器。
- **啟用開關：** 用於開啟或關閉現有 MCP 伺服器。關閉後，AI 將無法使用該伺服器，直到重新開啟。
- **健康狀態：** 綠點表示 MCP 伺服器已連線且運作正常；紅點表示伺服器無法使用或狀態異常，呼叫前應檢查其設定或程序。

![輸入欄中插入的 MCP 參照](/dialog-box/mcp-invocation-reference.png)

## 技能

指標突顯輸入托盤中的 **Skills（技能）** 按鈕。開啟後可管理 Breezell 提供給 AI 使用的技能。

![官方內建技能面板](/dialog-box/skills-built-in.png)

技能面板分為兩個分頁：

- **Built-in（內建技能）：** Breezell 官方內建的技能，無需自行建立或設定即可使用。
- **My Skills（我的技能）：** 由你自行設定或建立的技能。

![我的技能面板](/dialog-box/skills-my-skills.png)

兩個分頁中的技能都可個別控制：

- **呼叫箭頭：** 點選後會在目前的輸入欄中插入 `@<技能名稱>`。傳送包含此提及的請求，即可讓 AI 呼叫所選技能。
- **啟用開關：** 用於開啟或關閉技能。關閉後，AI 將無法使用該技能，直到重新開啟。

![輸入欄中插入的技能提及](/dialog-box/skill-invocation-reference.png)

## 訊息容量

指標突顯輸入托盤中的 **Message Capacity（訊息容量）** 按鈕。訊息容量用於分析已儲存對話占用的本機儲存空間；它不是模型內容視窗用量，也不是應用程式目前占用的執行記憶體。

![訊息容量按鈕](/dialog-box/message-capacity-button.png)

訊息容量面板提供以下資訊和操作：

- **統計範圍與時間：** 可在目前工作區和所有工作區之間切換，並檢視最近 7 天、30 天或 90 天的資料。
- **目前用量與趨勢：** 顯示本機儲存總用量、所選期間內的變化，以及儲存空間成長趨勢圖。
- **儲存分類明細：** 分別顯示訊息內容、圖片與附件、工具結果及檢查點的占用；虛線表示可回收空間。
- **摘要指標：** 顯示對話數量、訊息數量、最大對話占用和可回收空間。
- **對話檢查：** 支援搜尋、排序、篩選和選擇對話。每個項目會顯示訊息數量、儲存大小和主要占用類型，並明確標示正在活動或存在排隊訊息的對話。
- **安全清理：** 用於回收面板標記為可清理的儲存空間。執行前請確認目前統計範圍、篩選條件和選取項目。

![訊息容量面板](/dialog-box/message-capacity-dashboard.png)

## 快取命中

游標會突出顯示輸入托盤中的 **Cache Hit（快取命中）** 按鈕。**Cache Broadcast（快取統計）** 面板用於彙整目前對話或工作區中的供應商提示詞快取重複使用情況。這裡顯示的是請求快取統計，與已儲存對話佔用的本機儲存空間和模型上下文容量無關。

![快取命中按鈕](/dialog-box/cache-hit-button.png)

快取統計面板提供以下資訊和操作：

- **統計範圍：** 可以在目前對話和整個工作區之間切換。
- **命中率概覽：** 比較今天、昨天和歷史總計，包括已記錄輪次、快取命中率和快取讀取量。
- **Token 用量：** 顯示輸入 Token、快取讀取、快取寫入和輸出 Token。快取讀取表示直接從快取重複使用、不必再次處理的輸入 Token。
- **節省估算：** 顯示節省的等效輸入 Token，以及根據公開標價估算的費用。該數值僅供參考，實際計費可能因供應商、模型和路由而異。
- **逐輪明細：** 顯示每輪請求所使用的供應商、模型、思考與速度設定、命中率、時間和耗時。選取某一輪後，還可以查看該輪的輸入、快取讀取、快取寫入和輸出總量。
- **命中趨勢：** 透過圖表查看從較早請求到最新請求的命中率變化。
- **快捷操作：** 可以複製統計摘要，或清除目前統計範圍內的記錄。

![快取統計面板](/dialog-box/cache-hit-dashboard.png)

供應商快取是暫時的。長時間閒置、重新啟動、更換模型或速度檔位，以及後端路由變化，都可能使命中率暫時顯示為 0%；後續請求可以重新預熱快取。


## 提及選單

指標突顯用於開啟提及選單的快速內容區域。提及選單可讓你將檔案、資料夾、MCP 工具和技能加入目前訊息。

![Breezell 對話方塊中的提及選單](/dialog-box/mention-menu.png)

當請求依賴特定工作區內容或外部功能時，可以使用此功能。加入正確的內容有助於 Breezell 在回答前了解應檢查或使用哪些內容。

## 使用提示

- 當請求依賴特定專案內容時，加入檔案或資料夾內容。
- Agent 是預設模式，也是大多數工作的建議自動工作流程。
- 只有在需要特定工作流程（例如先規劃或只分析而不編輯）時才切換模式。
- 內容壓縮會自動執行。只有在偏好嚴格手動控制或有特殊要求時，才使用手動壓縮。
- 當準確性、速度或推理深度很重要時，請檢查所選模型。
