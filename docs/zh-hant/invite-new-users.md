# 邀請新使用者教學

Breezell 會為您的帳號產生專屬邀請連結，您可以將它分享給新使用者。符合條件的受邀使用者完成註冊並接受邀請後，相關進度會計入 Entanglement 和 Teams 的解鎖進度。

## 開始前

請確認您已有 Breezell 帳號，並且已登入官方網站。

## 開啟官網和個人選單

1. 開啟 Breezell 官方網站：[https://breezell.com](https://breezell.com)。
2. 如果尚未登入，請先登入您的 Breezell 帳號。
3. 點選頁面右上角的個人頭像。

![Breezell 官網中醒目顯示的個人頭像](/invitation-guide/open-profile-menu.png)

## 進入 Profile 頁面

1. 在帳號選單中找到 **Profile**。
2. 點選 **Profile** 進入個人資料頁面。

![帳號選單中醒目顯示的 Profile 入口](/invitation-guide/select-profile.png)

## 產生邀請連結

1. 在 Profile 頁面左側選擇 **Account**。
2. 找到 **Unlock Entanglement and Teams Modes** 區域。
3. 點選 **Generate invite link**。

![Account 頁面中的 Generate invite link 按鈕](/invitation-guide/generate-invite-link.png)

::: tip 提示
如果暫時無法讀取解鎖狀態，請先登出帳號並重新登入，然後返回 Account 頁面再次查看。
:::

## 將邀請傳送給朋友

產生連結後，Breezell 會提供類似下面的訊息：

```text
Can you help me unlock this? I'm waiting in the Breezell editor.
https://breezell.com/mode-invite/entanglement?token=YOUR_INVITE_TOKEN
```

上面的 Token 僅為預留位置範例。請複製您自己帳號實際產生的完整訊息和連結，然後傳送給朋友。

您的朋友可以開啟連結，完成註冊或登入，並接受邀請。符合條件的新使用者完成所需註冊流程後，會計入您的解鎖進度。

## 為什麼需要這樣做

很抱歉此次調整可能為您帶來不愉快的體驗。Breezell 需要持續的資助，用於承擔基礎設施、維護和後續開發成本。

感謝您對專案的支持，也感謝您協助 Breezell 實現長期穩定營運。
