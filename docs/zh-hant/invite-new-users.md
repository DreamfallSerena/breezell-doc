# 邀請新使用者教學

所有付費方案都包含 Entanglement 和 Teams。使用 Free 方案時，只要有五位 Breezell 使用者透過你的專屬邀請連結為你助力，就能**永久**解鎖這兩個模式。

::: tip 關於本頁的畫面
下方的畫面是根據 breezell.com 和 Breezell 的原始碼以 HTML 重新繪製而成。官網提供中文和英文兩種語言，因此和真正的網站一樣，官網畫面在本指南的中文頁面上顯示中文，在其他語言的頁面上則顯示英文。
:::

## 開始之前 {#before}

- 你需要一個 Breezell 帳號。請使用你在編輯器中所用的同一個帳號登入 [breezell.com](https://breezell.com)。
- 為你助力的好友需要有自己的 Breezell 帳號。他們可以在接受你的邀請時註冊。

## 1. 開啟你的帳號設定 {#open}

登入 [breezell.com](https://breezell.com)，點選右上角的頭像，再點選 **Profile**。

<BzWangzhan ye="caidan" gaoliang="profile" biaoji="1" />

進入帳號頁面後，點選左側欄中的 **Settings**。你也可以從側欄底部的帳號選單（**Account settings**）直接前往。

## 2. 產生你的邀請連結 {#generate}

Settings 中會顯示解鎖卡片和你的進度。點選按鈕即可產生連結：

<BzWangzhan ye="shezhi" :jindu="2" gaoliang="shengcheng" biaoji="2" />

連結產生後，卡片上會顯示這個連結，按鈕則會變成重新產生連結和複製連結。你可以在這裡試試看：

<BzWangzhan ye="shezhi" :jindu="2" lianjie gaoliang="fuzhi" biaoji="3" />

複製時，剪貼簿中會放入一段簡短的訊息和你的連結：

```text
「可以帮我助力吗？我在 Breezell 编辑器等你」
https://breezell.com/mode-invite/entanglement?token=YOUR_INVITE_TOKEN
```

上面的 token 只是預留位置：請傳送你自己的帳號所產生的文字。

## 3. 好友為你助力 {#assist}

你的好友開啟連結後，如果尚未登入，需要先登入或註冊：

<BzWangzhan ye="yaoqing" zhuangtai="weidenglu" />

接著只要點一下即可確認助力：

<BzWangzhan ye="yaoqing" gaoliang="zhuli" biaoji="1" />

頁面會確認助力已完成，並顯示你最新的進度，例如 3/5。

<BzWangzhan ye="yaoqing" zhuangtai="chenggong" />

### 助力規則 {#rules}

- 累積五次助力，即可為你的帳號永久解鎖 Entanglement 和 Teams。
- 每個帳號只能為一位使用者助力解鎖。已經為其他人助力過的好友會看到這則訊息：

<BzWangzhan ye="yaoqing" zhuangtai="yizhuli" />

- 每台裝置只能用來助力一次。
- 你不能為自己助力。
- 任何付費方案都包含這兩個模式，不需要助力。

## 4. 查看你的進度 {#progress}

你的進度會顯示在 Settings 的解鎖卡片上，也會顯示在編輯器中：開啟輸入框下方的模式選單，將游標移到 Entanglement 或 Teams 上即可查看。

<BzLiaotian tanchu="moshi" moshi="agent" suoding />

第五次助力完成後，鎖頭圖示就會消失，兩個模式都可以選擇。如果官網無法讀取你的解鎖狀態，卡片上會顯示提示並提供重試按鈕；你也可以試著登出後再重新登入。

## 為什麼採用邀請制 {#why}

Breezell 需要持續的資金來支應基礎設施、維護和開發。邀請好友讓你不必購買方案也能解鎖進階模式，同時幫助 Breezell 成長。感謝你的支持。1.2.8 版本的變更內容，請參閱[1.2.8 版本調整說明](/version-1-2-8-access-update)。
